# Lucide interface icons

The SVG geometry comes from the Lucide components in the pinned
`dioxus-icons` 0.1.0 crate used by PTTStella's Dioxus settings, context menu and floating toolbar.
The crate identifies its source as Lucide v1.14.0 at
`56e49f12166312f04af4cfd862621c93cf583979`. Each file keeps the
24×24 view box, two-unit stroke, and rounded caps and joins. Slint
uses the white strokes as masks for the interface palette.
