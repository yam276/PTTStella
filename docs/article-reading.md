# 本機文章閱讀快取

目標：讀文章與展圖時，移動、站端重繪及翻頁不撤掉已讀內容；捲動優先留在本機，只有未取得的邊界才向 PTT 取頁。僅適用已辨識、連線正常且採本機滑鼠導覽的 PTT 閱讀頁，其他站／未知畫面保留原始介面。

## 所有權與界線

Rust `SurfaceState` 擁有 `ArticleCache`；來源是同一名單投影的完整格線與共同 `ArticleReading` 行號，JS 不解析 ANSI、頁尾或文字。原始 Screen／Connection 不改為文章模型；`Paint.source_frame` 保留當前站端畫面，`Paint.frame` 是合併後的閱讀投影。選取、完整網址、媒體准入與輸出仍由同一已 ACK 投影及 source generation／revision／input epoch 驗證，歷史 link index 不直接對應站端畫面。

快取只存記憶體，最多 256 個連續正文行及一份頁尾；超連結 metadata target 合計最多 512 KiB。相鄰／重疊頁按絕對文章行號覆蓋合併，不插入猜測內容；超限移除遠端邊緣。跳到不連續位置時另起一段，已確認的較短文章結尾會移除舊尾端。開頭三行改變亦撤掉舊段，避免沿用不同文章的尾端。

作用域由 session、名單版本與實際輸入維持，並非完整 AID 辨識。離開文章、非閱讀指令、原始輸入、切站、斷線或規則改變清理；短暫分段刷新不當作換篇。沒有磁碟保存、全文預抓、背景讀文或跨 session 復原。

## 操作與取頁

滾輪、Page Up／Down、方向鍵及 Rust 轉譯的 Vim 閱讀意圖先移動本機位置；圖片使用同一捲軸。已載入內容可往返，站端等待中仍可捲動本機內容。Home／End 先移到已載入範圍端點，再於邊界要求站端跳轉。Vim 計數仍由 Rust 解讀；`i`／原生一次暫回原站端畫面，重新正常閱讀時建立新快取。

目前可見正文上／下半部的單次點擊亦使用上／下頁意圖，先本機捲動、再於未知邊界取頁。左側 17 欄返回優先，網址維持開啟，展圖區不攔截成翻頁；拖曳與 Shift 可選字，不覆蓋圖片或文字新增透明操作層。點擊交易必須保持文章、來源 stamp 及可視幾何一致，詳見 [滑鼠導覽](navigation.md)。

走到未知邊界，使用同一 navigation planner 與命令 owner 發出一頁。若站端仍停在快取另一端，Rust 逐頁移到所需邊緣，只有收到新 revision、確認有進展、對應畫面已 ACK 且本機互動 gate 允許後才繼續，最多 14 步。已取得目標、已到站端首尾、無進展、命令失敗、換畫面或清理就停止。不因普通 paint 或捲回已知內容自動翻頁，也不預抓整篇。

互動 gate 與保活 gate 共用有版本的 UI 狀態通知、分開表示可用性；設定、其他 modal、工具開啟、組字、拖曳與匯出期間不續送。每次送出仍核對最新共同畫面、來源 stamp 及現有輸入准入。

## 排版、複製與匯出

JS 只為可見文字行及上下兩行建立 Canvas，沿用共同雙色 renderer；總快取行數不成為單張巨大畫布。圖片顯示及載入上限見 [媒體](media.md)。圖片變高、前端新增較早內容或遠端舊行被移除時，以絕對文章行與行內偏移保持閱讀錨點。切換閱讀作用域重置捲動位置。閱讀中的隱藏鍵盤輸入框保持在可視區，避免 WebView 自動捲動到長文件尾端；組字／原始輸入會回到站端畫面及游標。

拖曳選字與完整網址複製消費合併後的 Rust 格線，不讀 JS 拼接文字。完整頁 PNG 仍輸出目前站端的 24 行，選取行 PNG 可從歷史內容輸出最多 24 行，不包含圖片。超長選取可複製文字，PNG 入口則停用並提示縮小範圍。

## 驗證

核心案例覆蓋獨立行文字 expected、重疊／缺口／首尾／雙向淘汰、文字行與圖片上限、分段輸出、來源及規則撤銷、歷史連結與雙色字。JS 使用生產排版與事件 handler 驗證有限畫布、錨點、來源 revision 改變不拆圖、僅邊界送出及禁止重複請求。原生 `inline_pages` 的 peer 只接受一次 PageDown，回讀快取必須零額外 bytes；圖片 HTTP 計數、歷史文字複製、PNG 與完整清理另核對，結果見 [active plan](active/minimal-browser.md)。
