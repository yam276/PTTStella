# 網頁文章全文載入

目標：網頁模式進入文章後自動取得全文，載入可取消、可繼續；已取得的文字與展圖可留在本機連續捲動。終端機模式維持原始逐頁操作。僅適用已辨識、連線正常且採本機滑鼠導覽的 PTT 閱讀頁，其他站／未知畫面保留原始介面。

## 所有權與界線

Rust `SurfaceState` 擁有 `ArticleCache`；來源是同一名單投影的完整格線與共同 `ArticleReading` 行號，JS 不解析 ANSI、頁尾或文字。原始 Screen／Connection 不改為文章模型；`Paint.source_frame` 保留當前站端畫面，`Paint.frame` 是合併後的閱讀投影。選取、完整網址、媒體准入與輸出仍由同一已 ACK 投影及 source generation／revision／input epoch 驗證，歷史 link index 不直接對應站端畫面。

投影保留當前頁尾的字格及 OSC 8 metadata，並一起移至投影末列；不累積歷史頁尾。網頁閱讀時用同一 renderer 將這一列固定於可見 BBS 區域下緣，正文與圖片在其後方捲動，不在文件末端重複繪製另一列。總頁數與指令沿用 PTT 站端頁尾；目前顯示行範圍依可見的快取畫面列更新（折行按畫面列計數，圖片沿用網址所在列）；配色依目前閱讀頁切換，保留該來源頁尾逐格的 ANSI 樣式（包含雙色字、亮色與反白）；目前頁數依可視文字起點最接近的來源頁起點更新，來源頁碼及折行後的畫面起點由 Rust 在接頁時保存。圖片內捲動沿用其網址所在的文章頁，不增加 PTT 總頁數；網頁模式的百分比改為本機閱讀進度，依目前可見範圍下緣占完整文件的比例計算，包含展開圖片的高度，以可見的內容末端為準；短文補齊的空白格線不算未讀內容。全文未取得時以 `--%` 表示總長度未知，載入控制仍顯示已取得行數。終端機百分比保持站端原值。Rust 只提供已驗證數字欄位的 cell 範圍，JS 以其擁有的排版幾何替換顯示數字，不解析站端文字或修改來源格線；同一整數百分比及目前頁數沿用頁尾 bitmap。來源 PNG 與文字選取仍保留站端原始資訊。頁尾上的完整網址仍可辨識及複製，不能只保留其顯示文字。

快取只存記憶體，不寫入磁碟或跨 session 復原。上限為 4,096 個連續畫面正文列、32 MiB 的估計 glyph／文字／hyperlink／推文 ID payload，（含來源頁尾逐格樣式），以及 512 KiB 超連結 target；來源頁面對應最多 8,194 筆。這是快取准入限制，不是程序 RSS 上限，Paint／解碼與 WebView 有自己的生命週期和容量。達上限或文章變動後，End／翻頁僅在已取得內容內操作，不跨缺口跳到站端尾頁；可切至終端機繼續。達上限保留已取得內容並停止，不再從開頭淘汰來假裝全文完成。可切至終端機模式繼續讀取。

PTT 頁尾回報邏輯文章行號，折行可能占用多個畫面列。Rust 依共同閱讀辨識結果及前後頁的可見 glyph 邊界核對重疊，將畫面列依順序接入；末頁從折行中間開始時，以實際畫面列的重疊為準，頁尾行號用於重複列的對齊取捨；接頁時另保留最多一列尚未確認屬於正文的來源尾端空白；只有下一頁首列與該實際格線重疊時才接入，不把終端機補白直接當成文章行。空白格只比較實際背景，非空白字仍核對文字及雙色樣式。向後接入新頁時，僅允許第一個重疊畫面列的前景色被站端重設為預設樣式：文字、字寬、欄位、映射及背景仍須一致，並保留已知文章列的原配色；第二列或改成其他非預設顏色仍停止。這處理跨頁 ANSI 前景色未被站端重繪延續的情況，不放寬真正文字／背景變更。以有界的來源行範圍→顯示列對應處理歷史頁面重繪，不以邏輯行號直接覆蓋折行。顯示列位置供 JS 錨點／媒體及本機可見行範圍使用，來源格線／PNG 仍保留原始邏輯行號。開頭三行變動、接頁重疊不符或讀取中出現缺口，保留舊內容並顯示文章改變，不補入猜測文字或宣稱完成。已確認的較短文章結尾會移除舊尾端。

作用域由 session、名單版本與實際輸入維持，並非完整 AID 辨識。離開文章、非閱讀指令、原始輸入、切站、斷線或規則改變清理；短暫分段刷新不當作換篇。自動載入只處理目前這篇已辨識文章，不追蹤其他文章、不自動下載內嵌圖片。

## 操作與取頁

滾輪、Page Up／Down、方向鍵及 Rust 轉譯的 Vim 閱讀意圖先移動本機位置；圖片使用同一捲軸。已載入內容可往返，站端等待中仍可捲動本機內容。Home／End 先移到已載入範圍端點，再於邊界要求站端跳轉。Vim 計數仍由 Rust 解讀；`i`／原生一次暫回原站端畫面，重新正常閱讀時建立新快取。

網頁模式的 PageDown、空白及下頁點擊以目前最後一個完整可見正文列作為下一頁頂列，保留一行閱讀銜接；不再固定只走正文高度的 90%。PageUp 保留原本第一個完整可見列，向上移動相應距離；小數縮放造成每列像素高度不同時可多保留一個邊界列。固定狀態列不算正文，末頁受實際捲動上限限制；圖片中沒有可銜接的文字時仍按可視正文高度減一行前進，不停在網址列。滾輪保持連續捲動，終端機仍使用站端翻頁。

一般模式的英文 `j`／`k` 與上下方向鍵使用同一本機逐行移動，不建立 textarea 文字輸入，也不必先開啟 Vim。中文輸入法組字期間暫停取頁並保留原文章，開始或取消組字不清空快取；完整確認的文字仍由原始輸入處理。輸入法送出的單一空白（普通文字事件或可信的組字確認）與一般空白鍵共用本機翻頁，不送成站端文字；若要在中文輸入法下以實體 `j`／`k` 瀏覽，使用 Vim Normal。Vim 計數、原生一次與輸入模式仍由原鍵盤政策管理。

目前可見正文上／下半部的單次點擊亦使用上／下頁意圖，先本機捲動、再於未知邊界取頁。左側 17 欄返回優先，網址維持開啟，展圖區不攔截成翻頁；拖曳與 Shift 可選字，不覆蓋圖片或文字新增透明操作層。點擊交易必須保持文章、來源 stamp 及可視幾何一致，詳見 [滑鼠導覽](navigation.md)。

進入已辨識的網頁文章即開始載入；若起始不在第一行，先經共同 navigation planner 送一次 Home，收到開頭後重新建立顯示列並清除舊的行內圖片位置，接著逐頁 PageDown。每次只有一個命令，使用既有 command owner 與 Connection 序列化佇列；收到完整站端頁面、核對新的有效範圍並接入快取後，文章作用域的 UI permission 仍允許即可取下一頁，不等待 Paint ACK。接頁由收到 View 時處理，繪圖只投影最新快取；載入期間合併更新，至多每 250 ms 建立一次全文投影，站端 input／output pending 時延後，完成或取消後立即投影。期限由同一 surface 迴圈擁有，沒有額外 timer task；仍最多一個 Paint 在途，舊 ACK 只釋放自己的畫面，不授權舊畫面操作。UI permission 以連線世代、文章 ID 與本機規則版本隔離，僅已知顯示／在途快照可授權；站端逐頁的 input／output pending 不撤銷此 permission，Rust 仍要求目前站端完整且沒有另一筆取頁。選字、組字、工具、modal、失焦或取消仍暫停／停止。完整保留開頭及已確認結尾時才標記完成；普通重繪或不變頁尾不當作前進。最多 8,194 步；單次等待 6 秒未收到有效新頁則停止，不無限重試。

「取消載入」或 Esc 停止後續命令，撤銷尚未執行的命令票據；已送出的 bytes 不能回滾，該頁稍後抵達仍可保留。「繼續載入」只接受目前 generation 與文章 scope，取消／逾時可繼續，文章改變／容量限制不自動續送。取消指令不依賴 revision，因此站端正重繪時仍可按；組字、選取、拖曳、對話框及工具的 Esc 仍由原功能優先處理。所有 deadline 由同一 surface 迴圈擁有，沒有獨立的背景 timer／送鍵 task。

自動載入時，到未知邊界的本機捲動等待同一載入工作，不再重複要求翻頁。取消後的未知邊界沿用手動取頁；新頁抵達並完成該次導覽後，接續原本的一次本機捲動，不需再按一次，也不因此重送取頁。只保留一筆、綁定 generation／文章 ID 的待完成意圖；換篇、斷線、取消、其他輸入／捲動或拒絕均撤銷，文章改變／容量停止不續行；若站端在快取另一端，最多 14 步接回所需邊緣。已取得目標、無進展、首尾、命令失敗、文章改變或清理均停止。對已知來源頁的重繪使用同一顯示列位置；無法對齊的未知反向接頁保守停止。

互動 gate 與保活 gate 共用有版本的 UI 狀態通知、分開表示可用性；失焦／隱藏、設定或其他 modal、工具開啟、組字、選字／拖曳與匯出期間不續送。載入提示分別顯示「視窗不在前景」或「操作中」的暫停原因；狀態變化不重送站端命令，回到可操作狀態仍由原 owner 繼續，可隨時取消。每次送出仍核對最新共同畫面、來源 stamp 及現有輸入准入。回覆於 UI 暫停期間到達時仍清理該命令的等待期限，不把已收到的頁誤記為逾時。

## 目前文章的推文更新

網頁全文完成且標準作者標頭可辨識時才提供「更新推文」。預設關閉，每篇需明確開啟；開啟先查一次，成功後每 5 秒再檢查，不保存偏好、不追蹤其他文章。Rust surface 擁有唯一 deadline，沿用 Connection 的 destination 工作與單一送鍵 owner，不建立輪詢 task、額外連線或另一份站端文字 parser。

PTT 閱讀器開啟檔案時保存當時長度，重繪或 End 不等於重新讀取檔案。因此更新先在完整尾頁送 Q，只有共同閱讀辨識及嚴格底部資訊框確認看板／AID 後才送空白返回列表；再使用既有 `Open` 流程定位 AID、Q 核對選取項目、進入同篇並核對原作者／標題／時間三行，最後以 PTT `:<原尾頁起行>` 回到原尾段。重新進入的中間畫面不替換閱讀投影、不撤銷原圖片 batch；收到同一 operation serial 的成功結果才允許接頁。依據為 [PTT pmore](https://github.com/ptt/pttbbs/blob/c591f7ca0222da541fa5098656a03f4668af2b5d/mbbsd/pmore.c) 與 [文章資訊／進出流程](https://github.com/ptt/pttbbs/blob/c591f7ca0222da541fa5098656a03f4668af2b5d/mbbsd/bbs.c)，實站不同部署仍需各自驗證。

保留既有快取與文章 ID，只核對重新取得的尾段／接頁重疊，再接入追加內容；沿用 4,096 列／32 MiB／連結預算，不每次重取全文。既有重疊文字或樣式不同、無法對齊、未知提示、刪文／換篇、等待逾時或容量上限均停止，不能跳過錯誤繼續取頁。這只驗證開頭三行及重新讀到的尾段，不宣稱能偵測未重新取得的中段修改；需要完整重讀時離開後重新進入。沒有新增內容也要確認新的完整尾頁，才安排下一個 deadline。每步等待最多 5 秒、重新進入整體 30 秒，續取頁仍使用原 6 秒期限。

JS 僅依 Rust 的標準推文列數及自己擁有的實際捲動幾何顯示未讀：任何閱讀位置（包含更新前的底部）皆交給既有錨點保留，不自動捲動；顯示新增列數，明確點提示才跳下去。展開圖片、等寬狀態與下載資源沿用同一文章 batch；不自動下載新圖片。計數以可辨識的標準推文列為單位，不解析 JS 文字、不推算跨行推文數，也不保存已讀位置。

更新準備前必須保持已 ACK 文章、generation／名單版本、前景、無選字／組字／工具／modal／匯出、無其他 command 或傳輸等待。暫停期間不補送錯過的檢查；重新可用後重新等待週期。若重新進入途中失焦、互動、取消或失敗，撤銷該工作並停止更新，保留已 ACK 文章與展圖為本機閱讀投影，不自動切回資訊框／列表、不改捲動位置。此狀態不再送取頁或相對瀏覽指令；普通 Left／Right／Enter／Backspace、滑鼠與 Vim 返回皆拒絕，明確 raw 文字／控制鍵仍可中斷。只有目前世代／文章且 trusted 的「顯示站端畫面」操作才清除投影，立即釋放圖片／hover owner 並呈現真正站端；換站／世代／模式／原始輸入也清理。已送 bytes 不假裝回滾。取消、手動非閱讀輸入、換篇、切站、模式／名單改變、斷線或關閉都撤銷 operation，晚到 View 不得送下一步或污染新文章。完成結果攜帶原 operation Stamp，即使 watch 合併略過 Active 仍只接收本工作的 Reached。取消經同一 Session 的控制 watch 優先處理，不占一般 64 格命令佇列；以來源 stamp 與取消當時的 request 序號截止，拒絕舊排隊工作，允許同一未變畫面的新明確請求。舊取消不覆蓋新控制，未來／外站世代 stamp 拒絕。手動原始輸入可中斷既有 Connection 工作，不等待 refresh 逾時。

## 排版、複製與匯出

文章內 `Cmd+F`／`Ctrl+F` 提供獨立的本機文字尋找，不攔截 `/` 或 macOS 的 `Cmd+Ctrl+F` 全螢幕。直接比對 Rust 已投影的 glyph，不重解 ANSI、推測折行語意或要求站端翻頁；查詢為逐畫面列的字面比對，不分英文大小寫。網頁模式查已載入內容，終端機模式只查目前頁，新站端畫面會清除該次查詢；排除頁尾及不可見的遮罩字格。查詢最多 256 UTF-16 units，命中保留最多 4,096 筆，超過時顯示 `+`。不保存查詢、不記錄到診斷或送往站端。

尋找列獨立管理焦點與輸入法；Enter／Shift+Enter 切換命中並循環，Esc 先關閉尋找，不取消全文載入。組字的 Enter／Esc 仍歸 IME；其他已開啟的對話框／情境選單保留按鍵優先權。開啟尋找時透過原閱讀 gate 暫停預讀／保活，關閉後依原保護恢復；不放寬失焦或切篇隔離。切篇、離開閱讀、切站／重連與關閉清除索引、查詢、timer 及反白；同篇名單投影更新重新比對並盡量保留目前命中。

命中以黃底黑字、目前命中以深藍底白字繪製；只是 live renderer 的局部樣式，不改 glyph、雙色來源、選取／複製或 PNG。網頁文字 bitmap 以尋找版本失效，圖片 batch、解碼、等寬狀態與幾何維持。索引只在有查詢時建立，位置使用緊密整數陣列；同一 frame 的輸入與捲動重用索引，輸入以 120ms 合併，不在每次滾動掃描全文。

網頁文章的可視捲動區沿用來源 BBS 欄列比例，在主視窗中等比例置中；全文列數與圖片高度只增加內部文件高度，不放大可視區。符合尺寸由主視窗計算，手動縮放仍在同一可視區內；視窗改變大小才重新符合，返回終端機則恢復原始格線容器。

JS 只為可見文字行及上下兩行建立 Canvas，另由共同雙色 renderer 產生一張單列頁尾影像；新 Paint、縮放或整數閱讀百分比改變時重建，不保存到磁碟。總快取行數不成為單張巨大畫布。頁尾沿用原投影列號，選取、網址與滑鼠命中使用其顯示後的幾何，不點穿底下的正文或圖片；翻頁距離扣除頁尾高度。短文章的格線高度與頁尾原位不變，離開網頁投影便釋放固定列。圖片顯示及載入上限見 [媒體](media.md)。圖片變高、前端新增較早內容或遠端舊行被移除時，以 Rust 顯示列與行內偏移保持閱讀錨點。切換閱讀作用域重置捲動位置。閱讀中的隱藏鍵盤輸入框保持在可視區，避免 WebView 自動捲動到長文件尾端；真正送出的文字／原始指令會回到站端畫面及游標；單純開始或取消組字不切換閱讀作用域。

拖曳選字與完整網址複製消費合併後的 Rust 格線，不讀 JS 拼接文字。完整頁 PNG 仍輸出目前站端的 24 行，選取行 PNG 可從歷史內容輸出最多 24 行，不包含圖片。超長選取可複製文字，PNG 入口則停用並提示縮小範圍。

## 驗證

核心案例覆蓋 441 行、取消／晚到頁／繼續、逾時不重試、中段 Home、折行及歷史頁對應、容量保留開頭，以及獨立行文字 expected、重疊／缺口／首尾／歷史頁回讀、文字行與圖片上限、分段輸出、來源及規則撤銷、歷史連結與雙色字。JS 使用生產排版與事件 handler 驗證有限畫布、錨點、來源 revision 改變不拆圖、僅邊界送出及禁止重複請求。原生 `full_load` 驗證 20 頁、取消／繼續、19 筆精確 PageDown 及零自動圖片 HTTP；完成後歷史展圖及本機回讀不加站端 bytes。`terminal_pages` 在第一頁保持靜止，僅一次手動 PageDown 可前進，全文控制與自動展圖皆不存在。原生 `inline_pages` 的 peer 只接受一次 PageDown，回讀快取必須零額外 bytes；圖片 HTTP 計數、歷史文字複製、PNG 與完整清理另核對，結果見 [active plan](active/minimal-browser.md)。


## 網頁與終端機模式

設定中心的「媒體」分類可保存文章模式。舊設定預設網頁模式，使用上述可取消的全文載入與本機捲動。終端機模式呈現原站端格線並使用站端翻頁，禁止 Enter／情境選單展圖及晚到的展圖結果；跟隨滑鼠與右上預覽保持可用。Vim 輸入模式等現有 raw-reading 條件仍可暫停網頁投影，偏好與當下有效投影分開管理。

保存成功才切換模式；切換取消取頁、內嵌圖片工作與舊畫面准入，清除文章快取、選取及暫時揭露，以目前站端頁面重新投影。不跨文章保存閱讀位置。回到網頁模式時重新開始全文載入，必要時回到文章開頭。

只有 Rust 確認的網頁文章投影可使用捲動條與本機閱讀捲動。文章列表、看板、選單、說明及終端機文章皆使用固定格線；普通滾輪在可操作畫面送上一頁／下一頁，放大或內容溢出不改成 WebView 捲動。未知／忙碌／選取／組字期間不送翻頁，也不讓終端機畫面自行捲動；Ctrl＋滾輪仍為本機縮放。

短文章仍保留來源 BBS 的完整欄數與至少 24 列高度，字格尺寸和縮放比不由內容長短決定；不足的行保留空白，狀態列位於格線底端。展圖先使用這些空白高度，內容與圖片超過來源格線時才增加文件高度；不把補列再加到圖片後面。網頁閱讀的裁切與 End／翻頁／滾輪共用 renderer 的實際文件高度，超出末端的捲動位置會收回，避免空白溢位延長捲動範圍。實際文章行號仍只表示已讀內容，不把空白補列計入文章長度。

長文接頁另以 `long_load` 本機合成 38 頁／837 列驗證，第 30 頁末列為黃色，第 31 頁同文首列回到預設灰；須完整載至末端，來源 PNG 仍使用站端樣式。回到前景或可見狀態時重新發布閱讀 gate，不必等待新的站端 Paint 才恢復。

可明確以 `PTTSTELLA_READING_TIMING` 環境變數指定新的 JSONL 檔案進行本機量測。只記單調時間、事件種類、連線／文章數字識別、revision、快取起迄與載入狀態，最多 8,192 筆；不記文章、URL、流量或帳密，預設不開啟。量測要排除登入、取得前景及導航準備時間，分別報告第一次 PageDown 至快取 complete、最終畫面 ACK 的時間；不同冷／暖連線或視窗尺寸須分列。

## 文章首尾方向鍵切換

「設定 → 圖片與媒體 → 文章首尾以方向鍵切換上一篇／下一篇」預設關閉，舊設定缺欄位亦關閉；保存成功後才生效並保留至重啟。網頁模式以目前實際捲動位置為準：先捲到頂／底，放開後再按 ↑／↓ 才換篇；按住方向鍵的 repeat 不跨文章。PageUp／PageDown、j／k、Home／End、滾輪與翻頁按鈕不觸發換篇。全文載入中不換篇，避免與未完成取頁競爭。

網頁模式的顯示位置與站端位置可不同，換篇由同一 Connection owner 先送 Home／End，保持輸入等待，收到完整且已辨識的對應首尾頁後才送 ↑／↓；站端原本就在該首尾時直接送方向鍵。中間定位頁不開放給文章快取或預讀，逾時、其他輸入、斷線或滑鼠路由變更不晚送方向鍵。Rust 重查設定、當篇快取、首尾是否已取得、ACK／stamp／input epoch、本機滑鼠路由及忙碌狀態；成功排入命令後清除文章快取與媒體作用域；直到來源 session 的 input epoch 與 revision 都前進才重新接收文章，不能在排隊空檔把尚未執行命令的舊畫面重新放入快取。舊載入結果不可污染新文章。終端機模式僅在辨識的閱讀首尾攔截普通 ↑／↓：設定關閉或 repeat 時不送鍵，設定開啟的獨立按鍵才切篇。中間仍沿用原始逐行操作，未知／編輯畫面保持原本輸入。

站端鍵位依 [PTT pmore 命令表](https://github.com/ptt/pttbbs/blob/90f07d655b8d7e85298ef26bdb63f40646fd9d17/mbbsd/pmore.c) 核對；部署版本與實站上下篇邊界仍需人工驗證。
