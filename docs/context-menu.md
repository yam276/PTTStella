# 右鍵操作選單

啟動時明確停用 WebView 預設右鍵選單，debug 與 release 行為相同。BBS 畫面使用本機選單，維持深藍與金色圖示；選單受視窗邊界限制，小視窗可捲動。對話框內的文字欄位維持系統編輯快捷鍵與 macOS「編輯」選單，目前不另外提供右鍵編輯選單。

## 情境與操作

已辨識網址（包含 OSC 8 跨行片段、快取文字及文章內插圖）上的普通右鍵優先開啟連結情境選單，提供複製完整網址、開啟連結／媒體預覽及選取完整網址，不要求 Shift，也不因開啟右鍵工具偏好而改成扇形工具。網址內的英文字串及所在推文列不提供帳號／只看 ID 操作；已有反白仍保留複製選取功能。非網址位置的文章可見完整帳號字串及已辨識文章列表作者欄開啟含兩種黑名單／白名單的情境選單；暫時只看某 ID 時右鍵也提供恢復全部。其餘位置預設無反白時，普通右鍵在游標附近開啟浮球的扇形工具，關閉後恢復浮球原位置；有反白或 Shift＋右鍵才開下列情境選單。站端滑鼠模式的普通右鍵仍回報站端，Shift＋右鍵保留本機選單。設定頁提供「右鍵開啟工具」與「顯示浮球」兩個獨立開關，自動保存成功後才生效；關閉右鍵工具會恢復原情境選單，包括進入設定的入口。隱藏浮球時，開啟工具期間仍暫時顯示中央按鈕，供返回分類及收合；錯誤與斷線提示不隱藏。version 5 自 v1–v4 補入預設值，載入不改寫檔案，儲存失敗不改生效設定；可攜顯示 profile 不包含此偏好。

| 點擊情境 | 操作 |
| --- | --- |
| 文章列表作者欄 | 遮內容保留 ID、整行塗黑、加入白名單 |
| 一般畫面 | 選取整頁文字、整頁 PNG、外觀與設定 |
| 已有選取 | 複製選取文字、複製含 ANSI 色碼、選取行 PNG；開啟右鍵不清掉選取 |
| PTT 發文／回文／信件編輯器 | 貼上剪貼簿文字；背景不開浮球工具，選取時仍可複製 |
| 已辨識網址 | 複製完整網址、開啟連結／媒體預覽、選取完整網址 |
| 已載入的文章插圖／完整圖片預覽 | 複製原尺寸圖片、另存原始格式、複製完整網址、開啟連結 |
| 閱讀頁背景 | 返回、上一頁、下一頁；在頁首／尾停用對應方向 |
| 閱讀頁背景含圖片 | 展開本頁圖片；沿用 Enter 的准入與有界載入，不收合 |
| PTT 背景 | 文章書籤、黑名單管理、Vim 切換 |

圖片、ID、網址與選取文字使用各自的內容選單，不加入上一頁／下一頁、整頁 PNG、Vim 或設定。選取文字保留複製文字與選取行 PNG（存檔／剪貼簿）；一般背景才保留整頁與全域工具。

書籤項目開啟既有管理視窗；黑白名單管理項目直接開啟統一設定的名單分類，不猜測目前文章 AID。文章內可見 ASCII 字串的快速名單與推文暫時篩選使用 Rust 候選、同一保存／投影擁有者，詳見 [本機過濾](content-filters.md)。不提供全文搜尋或站端名單交易。非 PTT 站點不出現 PTT 專用項目。

站端要求滑鼠回報時，普通右鍵保持原先 press／release 交易；Shift＋右鍵開本機選單。站端模式下的本機選單可複製與匯出，連結開啟與文章內展圖依既有 Local route 限制停用，避免同一手勢同時走兩條管線。

## 所有權與版本

`surface-context-menu.js` 只管理顯示、焦點、鍵盤與選單快照。方向鍵、Home／End、Enter／空白與 Esc／Tab 在本機處理；選單外點擊只關閉選單並消費該手勢，不順便點開底下文章。畫面版本、session、輸入 epoch、滑鼠路由或選取 request 改變即使快照失效；新投影到達時關閉選單，每次執行另核對快照與最新能力。失焦、resize、外部捲動與關閉均撤銷選單，清理移除同一組 listeners。

選單與浮球共用既有功能 owner，傳遞原生事件的 trust，不透過合成 `.click()` 假裝操作。導覽、圖片與 PNG 仍在 Rust 准入。右鍵不解析 terminal bytes、文章文字或 URL。

右鍵複製傳送封閉的選取 request 或 link index，不接受任意文字。Rust 以已 ACK 且已過濾的投影取得文字／完整目的地；過期、遮黑後消失的網址與不存在索引拒絕。剪貼簿採 `arboard` 3.7.0（MIT／Apache-2.0，文字與圖片功能）。單一 Files 工作槽序列化 OS 寫入、拒絕忙碌請求；寫入前重查可撤銷的 OutputLease 及 connection watch。已開始的 OS 操作會 join，不宣稱可回滾；不記錄剪貼簿內容。只有明確在已辨識的 PTT 編輯器點「貼上」才讀取系統剪貼簿，讀取前後及完成時重查來源、輸入 epoch 與投影；錯誤或過期不送出。剪貼簿 owner 保留至正常清理，符合 Linux selection 的生命週期；其他平台仍須實測。

圖片輸出沿同一 Files 工作槽與 OutputLease，inline 只傳已 ACK 投影的 link index／stamp，完整預覽只傳 request；Rust 解析自己持有的原始 Arc 資源，不接受 JS 提供 URL 或 pixels，也不為複製／另存再次下載。重試／關閉預覽、切篇、session／輸入／投影變更會撤銷尚未寫出的來源；已開始的 OS 寫入仍 join。未成功解碼或 hover 預覽不能輸出原圖。

複製由 image 0.25.10（MIT／Apache-2.0）在 blocking worker 依既有 8 MiB、8192 邊長與 16M 像素限制解碼，保留原始解析度，GIF／動態 WebP 取首幀；另存使用已載入的原始 bytes，保留原格式／動畫，以時間命名並要求保留副檔名。完整預覽在 modal 內共用同一選單控制器，Esc 先關選單，外部點擊不穿透。

⌘C／Ctrl+C 保留原生 copy event 與 Rust 預備選取結果，不依賴右鍵路徑。PNG 繼續使用原始格線 renderer，不包含選單、游標、反白或文章內插圖；正常模式由使用者選擇儲存位置。

## 驗證

一般 gate 跑 desktop lib／bin、core、Clippy、Fluent 與全部 JS 測試。單元涵蓋內容與能力、未受信任／過期事件、邊界定位、鍵盤、外點不穿透、選單清理、完整網址索引、插圖命中、剪貼簿背景工作／拒絕／撤銷／失敗及 join。

原生 `--probe-surface OUTPUT_DIRECTORY context_menu --media-origin http://127.0.0.1:PORT` 使用自製閱讀頁與固定游標位置，便於透過原生 accessibility 在 URL 上右鍵。圖片 peer 僅提供 colours.png 與 missing.png（404），BBS peer 拒絕全部站端輸入。必須實際複製選取及完整網址、至少兩次展圖只建立一次 batch、匯出 PNG，並正常 Close／清理；報告至少兩次成功剪貼簿寫入。還須在本機草稿以原生貼上讀回，不能只靠成功計數。任意 DPI、站端 Shift 手勢與其他平台分開驗收，不能用此固定焦點案例代替。

「設定」使用金色品牌符號及標籤，開啟可搜尋中英文功能的主視窗內的設定對話框；與浮球入口及 ⌘,／Ctrl+, 共用同一個對話框擁有者。

原生 `picture_menu` 案例使用同一合成閱讀頁與自製兩色圖。需從文章插圖與完整預覽各複製一次原圖（OS 剪貼簿讀回）、另存一次原始 bytes、複製一次完整網址、匯出來源格線 PNG，再正常 Close。runner 獨立核對原圖尺寸／紅藍像素、存檔 bytes、HTTP 次數及全部 worker 清理；不可只看動作計數或退出碼。

0.2.1：Rust 從已 ACK 的過濾後選取序列化 ANSI SGR，逐行 reset，SGR 66 保留雙色中文字。一般複製不附色碼。編輯器辨識要求完整 80×24 格線、正文游標、底列「編輯文章」的色帶及 ^X／^V，未辨識畫面維持既有行為。Ctrl+V 在編輯器送站端 0x16；Cmd+V／Ctrl+Shift+V 與右鍵負責貼上。只接受有界 SGR 色碼，ESC 轉成 PTT 編輯器的 Ctrl+U 插入字元；其他控制碼整段拒絕，含色碼或多行一律先預覽。確認時再次檢查 session、revision 與 input epoch，不能把舊內容貼入新畫面。站端語義參考 [PTT editor](https://github.com/ptt/pttbbs/blob/main/mbbsd/edit.c)。
