# 本機撰寫與草稿

在已登入、已辨識的看板文章列表，Ctrl+P 或浮球「導覽 → 本機撰寫／草稿」開啟本機撰寫。若該帳號在同一站點／看板有草稿，先列出標題、保存時間與衝突標記，由使用者選擇繼續、另寫或使用 PTT 編輯器。沒有草稿時直接建立空白編輯介面；尚未輸入不建立磁碟項目。原生發文快捷鍵只在可靠辨識的列表攔截，其他畫面維持原指令。

本機正文保存完整 UTF-8 中文及原始 ESC SGR，不從站端23行畫面猜測全文。編輯區以 `␛` 顯示 ESC；真正的字面 `␛` 用雙符號表示，往返不混淆。可框選正文後開色彩表，多行獨立上色、空行略過、保留未選取區原有樣式；不完整色碼可以保存，彩色預覽與帶入前須通過既有安全 SGR grammar。彩色預覽只使用 Rust Screen 與共同 Canvas renderer，沒有 HTML 或另一個 JS ANSI parser。

## 自動保存與多開

正常輸入停頓180ms、離開編輯區、失焦／隱藏或明確保存時提交；IME組字期間不提交半成品。JS同時最多一筆待回覆保存及一份最新編輯；Rust保留一個背景磁碟task與一份合併後最新快照，檔案鎖／備份／原子替換共用storage Document。斷線不關閉或清空本機編輯器；正常關閉App經renderer最終快照補存尚未觸發debounce的修改，並join磁碟owner。未顯示「已保存」的文字遇到斷電／強制終止可能尚未落盤，不冒稱逐鍵同步持久化。

每份草稿具穩定ID、site／account／board scope、revision。儲存交易在kernel lock內比對開啟時的整份baseline；同稿被其他視窗更新或刪除時，另存新的衝突副本，兩份都保留，後續自動保存接續副本。不同稿保留彼此更新。刪除也檢查精確baseline，不能刪掉另一個視窗的新修改。主檔損壞或容量不足會報錯且不覆寫主／備檔；沒有默默用空集合恢復。清單不即時同步其他視窗，重新開啟會重新讀檔。

資料位於ProjectDirs的本機data目錄 `drafts.json`，不在repo；unix新檔權限依storage現有0600路徑。最多64份，正文每份128KiB／4096行，標題256 UTF-8 bytes，JSON含escaping最大12MiB。滿額拒絕，不自動淘汰。清單可確認刪除；上一代 `.json.bak` 可能保留內容，不代表安全抹除。草稿、標題與帳號不進診斷log。不能辨識登入身分時不猜測帳號或讀取其他帳號草稿。

## 帶入與站端界線

先保存，再按「進入 PTT 發文流程」。Connection唯一writer在當下重新核對stamp、account、board、PTT capability、穩定完整畫面及無其他命令，才送一次Ctrl+P。分類與標題由使用者依站端提示完成；本機標題供參考，不自動繞過板規或分類提示。PTT進入編輯器後出現草稿入口，開啟原稿、按「帶入正文」並另按確認。

Connection再次核對相同流程token／generation／scope、fresh stamp及空白80×24標準編輯器／開頭游標，才將正文一次送出。已有範本或正文先由使用者處理，拒絕覆蓋。跨板／回主選單／閱讀頁／重新連線／Ctrl+X／另開原生發文使lease失效；最長10分鐘，不能冒用過期流程。SGR以PTT的Ctrl+U插入ESC，換行轉CR；禁止Ctrl+X、游標控制、OSC、未知SGR及其他控制字元。每行最多79終端欄／510編碼bytes，過長先分行；未映射字元拒絕而不替換。

帶入成功只表示傳輸write完成；不代表站端全文驗證或發表。原稿繼續保留，任何失敗都不重送，永不送出發表／存檔指令。站端後續修改不自動回存本機，發表後也不自動刪除草稿。第一版範圍為新發文，沒有回文或信件全文備份。

## 驗收

一般測試使用自製中文／SGR，不接PTT。Rust覆蓋儲存重開、原子備份／損壞／上限、精確衝突與刪除、最後快照、色碼與選取樣式；真正兩程序同時修改同稿／新增不同稿。Production Connection loopback精確核對Ctrl+P與一次ANSI正文，拒絕錯帳號／舊stamp／錯token／控制碼及重送；peer不接受任何發表bytes。JS驗IME／debounce／來源可逆／失敗不丟稿／明確恢復及二次確認／清理。原生macOS以drafts與drafts_restart確認實際輸入、彩色預覽、檔案保存與新程序讀回／帶入；Windows／Linux GUI另行實測，不能以macOS代表。
