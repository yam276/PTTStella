# 本機撰寫與草稿

## 先取得看板範本

Ctrl+P 保留 PTT 原生發文流程，先由使用者選分類、填標題。進入站端編輯器後，按「本機撰寫／草稿」讀取標題與完整預設內文；此時才詢問同站點／帳號／看板的舊稿要恢復或使用目前範本另寫。看板列表的浮球入口只管理／恢復已存草稿，不會建立跳過範本的空白新稿。沒有確認登入身分時不猜測帳號。

正文不是擷取目前23行：Connection 使用標準 PTT 編輯器指令，核對檔案處理選單後僅走 `(T)改標題` 讀回原標題並原樣結束，再切色碼原文、檔尾取得行數、回開頭逐行以 End 證明完整長度。畫面外中文、ANSI 與末尾空行皆保留。原文模式的 `*[...m` 經既有 Row capture 還原為 ESC；無法證明完整的過長行（原文超過79欄）、未映射或不支援色碼會停止，留在站端供手動繼續，不假裝匯入成功。

## 編輯顯示與選取

介面以標題和大面積正文為主，分類留在原生流程及標題。CodeMirror 6 管理本機文字、IME、游標、復原／重做和可見區 DOM。三種顯示共用同一份原始文件與歷史：

- 彩色編輯：所見即所得，可直接輸入；隱藏完整 SGR，Rust Screen 投影文字左右樣式；方塊／三角使用原有共同 Canvas renderer，不靠字型留白填格。
- 隱藏色碼：保留一般文字編輯，隱藏 SGR，不套色。
- 色碼原文：顯示真正的原始碼，ESC 以控制字元圖示顯示。字面的 `␛` 不需轉換，也不與 ESC 混淆。

編輯區依可用空間等比例縮放，保持79欄、23列的可視字格（半形1格、中文2格，字格寬高1:2），長文在編輯區內捲動。介面文字與控制項隨視窗放大；視窗變小時縮放可視格線，不改寫草稿。此為可視範圍，不把整篇限制為23行，也不自動裁切或重排已有ANSI；帶回PTT仍檢查每行79可見欄的限制。

不完整色碼保持可見可改、可以保存；不會因切換顯示而剝除或重建原文。SGR 由 Rust 安全 grammar 和生產 Screen 解析，JS 不重解 ANSI，不將文章放入 HTML。圖形 widget 的格線選取不切開 Unicode 中文字元。

預設「文字選取」可選一行中的部分文字或跨行選取；「整行選取」另供拖曳按首末行完整選取，單擊仍可定位插入點；「ANSI 圖：矩形」依滑鼠位置跨行選取字格。框選後右鍵直接顯示浮動16色前景／8色背景色票，點一色立即套用，選單不占編輯排版空間。多行各自上色、空行略過，保留未選區的樣式；矩形各行只上選中區。上色為一次可復原的編輯。色彩請求使用記憶體中的完整原文和 revision，不等磁碟保存；舊結果不能覆寫新編輯。矩形上色共用單次詞法掃描，不逐行重掃整篇文件。

Runtime bundle、MIT授權及來源清單在 `assets/vendor/composer/`。一般 Cargo 建置不需 npm；維護來源、鎖定套件及 DOM 測試在 `tooling/composer/`，用 `npm ci --ignore-scripts --prefix tooling/composer`、`npm run build --prefix tooling/composer`、`npm test --prefix tooling/composer` 重建／驗證。套件來源為官方 npm registry。發佈包的 licenses 與 Windows 內嵌 notices 包含編輯元件授權。

## 自動保存與多開

一般輸入停止2秒後保存，連續自動保存至少間隔5秒；移動焦點到標題、色票或模式按鈕不保存。明確保存、關閉編輯器或視窗失焦／隱藏會盡快補存。IME組字期間不提交半成品。顯示「有修改」期間不鎖住輸入；磁碟工作同時最多一筆與一份合併後最新快照。讀取範本本身亦保存成可恢復草稿，未匯入且未輸入不建立空檔。

斷線保留本機編輯器；正常關閉 App 經 renderer 最後快照補存 debounce 中的修改，join 磁碟 owner。未顯示「已保存」前遇到斷電／強制終止仍可能尚未落盤，不宣稱逐鍵同步持久化。關閉會銷毀 CodeMirror、listeners、計時器與視圖 observers，保留已確認的最後原文。

保存沿用 storage Document 的 kernel lock、備份與原子替換。每稿有穩定 ID、site/account/board scope、revision，交易核對開啟時的完整 baseline；別的視窗更新或刪除同稿時另存衝突副本，後續接續副本。不同稿保留彼此修改。刪除也核對 baseline。損壞、容量或磁碟失敗保留舊資料、回報錯誤，不默默重置為空集合；清單重新開啟才讀入其他視窗更新。

資料在 ProjectDirs 的 data 目錄 `drafts.json`，不在 repo。最多64份，每份正文128KiB／4096行、標題256 UTF-8 bytes，JSON上限12MiB；滿額拒絕，不淘汰。新檔 unix 權限沿用0600。確認刪除不代表抹除備份，上一代 `.json.bak` 仍可能保留內容。正文、標題與帳號不寫入診斷 log。

## 帶回 PTT 的界線

保存後按「帶回 PTT 編輯器」，再明確確認。Connection 唯一 writer 核對 generation、stamp、站點、帳號、發文 scope、完整穩定畫面、無競爭命令與本機匯入 baseline；重新讀取整份站端標題／正文並逐字比對。任一改變便停止，不覆寫手動修改。

確認相同後，僅透過已核對的 `(T)改標題` 提示修改標題，回到正文開頭，按已知行數清除原範本並驗證確實空白，才送一次新正文。必要時暫開插入模式，結束恢復模式。SGR 用 PTT Ctrl+U 插入 ESC，換行轉 CR；正文只准安全 SGR，禁止 Ctrl+X、OSC、游標控制和未知控制碼。正文每行最多79可見欄／510編碼bytes；標題不可空白或含控制字元、最多60編碼bytes。無法編碼會拒絕，不替換字元。

只有讀／改標題流程會進入檔案處理選單，**不選 S、預設選項或發表**。正文傳完仍停在原生編輯器，由使用者檢查和自行發表；本機原稿保留，站端後續修改不自動回存。傳輸部分失敗不重送，已寫入的內容不能假裝回滾。手動操作、取消、切站、重連和關閉會停止工作；取消時可能留在原生選單，依站端提示選 E 繼續。回列表／主選單／閱讀頁、Ctrl+X／另開原生發文會撤銷原 scope，最長1小時。每步5秒、全文工作180秒和步數上限維持有界。第一版只支援新發文，不當作回文／信件全文備份。

## 驗收範圍

一般測試只用自製中文／SGR與loopback，不接PTT、不發表。Rust核對畫面外31行、末空行、標題／樣式、真正來源變更拒絕、過長行／假選單拒絕、排隊取消、原生scope、保存關閉／重開／衝突。兩程序測同稿衝突與不同稿保存。JS clock測2秒／5秒、組字、內部焦點不保存、錯誤分類、晚到結果、浮動色票立即套用、兩次確認及清理；實際CodeMirror DOM測顯示切換、原文相等、復原重做、跨稿歷史隔離及共同圖形widget。

macOS 用 `drafts`／`drafts_restart` 原生探針核對範本、中文、色碼切換、右鍵色票、保存與重開帶回。peer只有標題 T/E、正文操作與Close，拒絕發表。原生拖曳／真實注音IME與跨平台GUI不能由DOM doubles或單一平台結果取代，實測／缺口見唯一 active plan。
