# 文字、固定排版與雙色字契約

本文件描述文字、固定格線、色彩與雙色字的產品行為及驗收要求。

## 最簡 terminal 必須保留

- 固定邏輯欄位與行高；縮放改變顯示尺寸，不把終端文字重新排成比例字體文章。
- ASCII、中文與常見終端圖形的欄位關係、空白、換行及游標位置正確。
- ANSI 前景／背景、反白、局部清除、覆寫及捲動依已支援控制碼作用於格線。
- 一個雙欄字形的左右 cell 可有不同前景／背景；仍是同一完整字形。
- viewport 佔滿視窗內容，工具列以 hover 浮層呈現，不推擠畫面。固定 80×24，以同一比例縮放寬高，符合視窗時可留黑邊；放大後可捲動，不拉伸或重新排字。
- 使用明確的 16 色：一般 RGB 色分量為 0／128，灰為 192；亮色分量為 0／255，亮黑為 128。SGR 1 啟用前景亮色、22 清除此強度，0 重設；90–97／100–107 仍保留站端明確選擇的亮色。不混白、不整體提亮，不因 SGR 1 額外加粗字形。

## 資料與繪製

Rust 核心保存逐 cell 的來源內容與樣式，控制碼先作用於格線，再由單一 mapping 邊界建立字形配對。不能先把整段 raw bytes 轉成 Unicode 再丟掉左右樣式；換色序列不應單憑其存在就中斷有效配對。

同一完整字形共用原點、baseline 與字型設定，再按左右 cell 的區域／樣式裁切；背景也分半處理。renderer 不把左右 byte 當兩個 Unicode 字元，字型自然寬度也不重新決定終端欄寬。

SGR 66 沿用同一 byte／cell 模型：[公開格式](https://github.com/ptt/pttbbs/commit/5bec38cc8a18f08a660c01611e31bda11078c212) 的 `ESC[31;44;66;32;45m` 保存遇到 66 當下的樣式供下一個可列印 cell 使用，後續參數改變一般樣式。因此緊接的 Big5 雙 byte 字仍配成一個完整字形，左紅／藍底、右綠／紫底；後續文字使用新樣式。這個暫存只作用一次，單寬字同樣消耗；同一 SGR 內再次 66 替換暫存，同一 SGR 的 reset 只改一般樣式。依 [PTT pfterm](https://github.com/ptt/pttbbs/blob/653523c29dc6d9207641ce7b4bb1d721d4ea1f53/mbbsd/pfterm.c#L1943) 的命令分流，後來的 ESC 本身不取消暫存；分開的 SGR（含 reset）、再次 66 及游標命令仍保留它直到下一個可列印 cell，實際 terminal reset 則清除。其他 C0／DEL 或 session reset 取消尚未消耗的暫存，不改舊格子，也不增加另一個字形模型。覆寫、捲動與行末沿用原有 cell 規則。本輪只驗證 Big5／UAO，沒有宣稱 UTF-8 decoder 已完成。

一般文字按字型自然比例置中於所屬欄位，不把每個字形橫向拉滿；超寬時等比例縮小以容納。這讓圓點、空心圓及雙圈符號不因不同 advance 而變成橢圓，同時維持固定 cell 位置與左右裁切。連接用的框線／陰影字元保留格線 fitting；已由幾何繪製的方塊／三角形不經字型縮放。沒有將所有符號替換為自畫圖案。

背景先全部畫完，再畫前景；cell 共用同一組整數實體像素邊界，避免獨立小數 fillRect 的抗鋸齒接縫。Canvas 各軸使用實際 backing store 的寬高計算共享邊界，包含各自取整後的最後一個像素；文章的單行 Canvas 不把較小的等比字型縮放值重用為兩軸邊界，以免行高進位時留下 1 pixel 黑邊。字型仍維持等比縮放。實心、分數方塊、象限及四向直角三角形使用格線幾何，兩半仍各自裁切／上色。陰影圖形與其他文字維持字型繪製，未宣稱所有藝術字元或字型皆完全相容。繪製 backing store 上限為 16M RGBA pixels（64 MiB）、每維 8192 pixels；縮放在資源上限內維持比例。

mapping 須有公開來源、版本及可使用的授權。通用 Big5 的支援不代表已證明所需 PTT／UAO 映射；未映射或非法內容明確回報，保留來源，不偷偷轉成另一個字。沒有取得適用映射時，測試可繼續，完整顯示相容性仍未完成。

## 合成案例與完成條件

| 案例 | 預期 |
| --- | --- |
| 中英文混排、空白及行邊界 | 固定欄位、字寬與 cursor 正確 |
| 同一中文字左右不同色／背景 | 完整字形共用幾何，兩半獨立樣式 |
| 雙 byte／SGR 內每個 byte 邊界切分 | 最終語意狀態與不切分一致 |
| 游標、清除、捲動與半格覆寫 | 受影響配對重新判定，不沿用過期字形 |
| 孤立、非法或未映射內容 | 有界處理、診斷明確，不跨不相關位置配對 |
| 框線、方塊及連續圖形 | 空白、行高、格寬與縮放接縫符合固定排版 |
| 圓點、空心圓、雙圈與含心圓 | 獨立解碼 PNG 的筆畫寬高接近，避免橫向拉伸；固定欄位與原始配色不變 |
| 字型／fallback／DPI | 在指定實際 backend 留畫面證據，不以其他 OS 結果代替 |

合成 fixture 只能證明指定規則。若要聲稱和參考客戶端一致，須在 repo 外留可使用的對照證據；產品測試仍使用自己的公開介面與可散布的資料。字重等影響字形的分半屬性需各自列明結果，不從顏色通過推定全部支援。
