# 介面語言

本階段選用 Project Fluent：Rust 使用 i18n-embed 與 fl! 編譯期檢查，WebView 使用官方 @fluent/bundle，兩者共用 locales/zh-TW 與 locales/en-US 的 pttstella.ftl。資源隨二進位內嵌，沒有執行期檔案或網路翻譯依賴。

翻譯 key 使用功能語意名稱；整句與具名參數由 Fluent 處理，英文複數使用 selector。站端內容、辨識提示、使用者輸入、帳號、板名及檔名資料不當作翻譯 key。文案以文字／屬性呈現，不插入 HTML。

語言在視窗事件迴圈啟動前固定。Localizer 可獨立建立供測試；應用程式的 OnceLock 只允許初始化一次，沒有可變的執行期全域語言或 thread-local 語言。背景工作與 UI 因此一致，偏好保存預定於下次啟動生效。未呼叫桌面初始化的核心工具與測試使用繁體中文。

第一批只建立載入器、兩語資源、JS bootstrap helper 與驗證；語言偏好、原生選單及產品 UI 的串接由後續功能提交完成，不將基礎模組測試算成產品視窗驗收。

驗證入口為 Rust i18n 模組測試及 node --test tooling/test_i18n.mjs。Rust 使用官方 Fluent AST 拒絕語法錯誤、重複 key 及兩語參數差異；兩種 runtime 均驗證獨立語言、具名插值與英文複數。產品串接後另執行兩語原生視窗、保存／重啟與既有輸入／PNG 回歸。
