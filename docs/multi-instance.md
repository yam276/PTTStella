# 多開與共用資料

每個視窗的連線、文章載入與記憶體狀態獨立。診斷記錄按每次啟動隔離，詳見 [診斷版](diagnostics.md)。多個視窗仍受 PTT 站端的同帳號連線限制，程式不自動代答刪除其他連線。

## 保存契約

設定、黑白名單、書籤與站點共用磁碟資料。每次保存以獨立的 `.json.lock` OS 鎖包住讀取最新版、三方合併、備份與原子替換。鎖檔保持存在，程序結束即釋放鎖；不刪鎖檔、不建立跨程序租約。等待最多約一秒，忙碌時回報失敗，磁碟工作不阻塞 UI 執行緒。

- 設定依欄位合併；工具入口組合、字型組合等需整體有效的值視為一項。
- 黑白名單以不分大小寫的 ID、書籤以看板與 AID、站點最愛以完整目標辨識。新增、修改及刪除只套用相對於該視窗實際編輯基準的變更，保留其他視窗的不同項修改。
- 兩邊修改同一項且結果不同時，拒絕這次保存並顯示衝突，不覆蓋已存內容。重新啟動該視窗載入最新資料後再修改；目前不提供背景即時同步。
- 最近看板只提交本次新增的造訪，不能用舊快照覆蓋全份紀錄。清空是交易屏障，另一視窗之後造訪新看板不會復原清空前的歷史。清空成功時備份也清空。
- 合併後仍檢查容量與格式；失敗不當作保存成功。既有毀損資料只沿用原本的明確恢復規則，不能覆蓋另一視窗剛寫入的未知內容。

所有並行視窗必須使用此修正後的版本。舊版不遵守新的鎖與合併協定，混用舊版仍可能覆蓋共用資料。帳密仍由既有 OS credential store 管理，本次未變更密碼保存與登入授權規則。
