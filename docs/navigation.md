# 滑鼠導覽契約

滑鼠操作沿用固定 80×24 格線。畫面辨識與導覽計畫由 Rust 唯一管理；UI 只消費已辨識的內容與命中區域，不解析文章文字，也不增加 shell／PTY。

目前完成：純 Rust 畫面辨識與輸入計畫、29 個合成正反例、production Connection 的版本／輸入競態往返，以及 Windows Dioxus／WebView2 的真實 pointer／wheel 往返。macOS 另驗證本機列表的 Vim／原生視窗流程；實站登入後及其他平台的滑鼠流程尚未驗證。

## 範圍與識別

第一版保守支援有日期欄的文章列表，以及 pmore 的一般「瀏覽／目前顯示行數」狀態列。需要標頭、操作列、有效項目、游標／選取記號等獨立條件；閱讀需要狀態列的格式、樣式與游標位置。未知畫面、判斷所需欄位的未映射字元、未結束控制碼、缺欄位及非 80×24 都不提供導覽。辨識是 heuristic，終端串流沒有語意畫面協定，不能保證抵抗刻意仿造整頁內容。

公開站端介面核對於 2026-10-16，來源為 ptt/pttbbs commit `90f07d655b8d7e85298ef26bdb63f40646fd9d17` 的 [列表欄位與操作](https://github.com/ptt/pttbbs/blob/90f07d655b8d7e85298ef26bdb63f40646fd9d17/mbbsd/bbs.c)、[閱讀狀態列](https://github.com/ptt/pttbbs/blob/90f07d655b8d7e85298ef26bdb63f40646fd9d17/mbbsd/pmore.c)。只依可觀察的文字／欄位介面編寫自己的判斷與合成資料，沒有搬入站端程式或私人 session。這不是實站部署版本的證明。

初期不支援價格式列表、所有自訂狀態列、橫向閱讀或所有彈窗。未辨識時保留手動鍵盤；不猜測自動登入、確認、發文、刪文或轉帳。

文章列依固定格線解析：游標區 1 欄、編號 6 欄、狀態／人氣 4 欄、日期 6 欄、作者 13 欄，後方才是文章標記與標題。人氣與日期可以直接緊貼（如 `+1610/16` 或 `m5110/16`），不能以空白分詞找日期。一般單格 `>` 指標可緊貼六位數編號，不要求後方空白；legacy 圓形指標覆蓋六位數編號首字時，只在該指標列接受數字尾段；不拿可見編號當全域索引。欄位日期／作者／標記仍各自驗證。

看板／最愛以標題色帶、編號／總數、看板、類別、人氣、板主等穩定欄位，以及固定板名欄、操作列與有效指標共同辨識。描述欄名稱（例如「中文敘述」或「中文測述」）不參與輸入判斷；缺少穩定欄位或項目欄位不符時仍暫停，並分別顯示看板標頭／項目欄位未確認。

看板／最愛的前進提示可為「進入」或「閱讀」，返回可為「回上層」、「回到上層」或「離開」；依標頭欄位判定 BoardList，不能僅因提示「閱讀」而判成文章列表。自製滿頁案例包含目錄、長板名、15 列一般文章與 5 列置底，不包含使用者截圖的帳號／最愛內容或私人流量。

一般列表接受五欄日期的補齊空白（例如 `1/ 9`）、一般／回覆／轉錄／投票／鎖文標記，以及作者為 `-` 且帶 `╳`／`□` 的刪文列。一列日期或標記不同不應讓合法看板整頁失去 Vim／滑鼠導覽；一般日期仍須有效；置底星號列另接受日期欄的「重要」。文章可有空白標題，仍須保留已知文章標記、合法編號／作者與完整列表條件；提示列、非法作者或未知標記仍拒絕。格式依 [公開列印介面](https://github.com/ptt/pttbbs/blob/908bb0631a4a6db41eac85713637adf1a6058fde/mbbsd/bbs.c#L711) 編寫自製正反例，沒有將實站登入視為已驗收。

共享辨識器提供主選單、看板／最愛／分類及標準進板暫停提示的鍵盤 profile，詳見 [Vim 瀏覽](vim-browsing.md)。滑鼠也可點選已辨識主選單項目（如個人設定、我的最愛）與看板／最愛／分類列。Rust 提供有效起訖與目前游標列，同一生產 planner 以相對方向鍵加 CR 進入；空白區、標頭與未知畫面沒有命中。此擴充不啟用主選單／最愛的防閒置。文章列表跨上方操作列及底列核對返回／閱讀提示；提示覆蓋不得藉由殘留標頭取得導覽。

## 互動與視覺

- 點已辨識的主選單項目或看板／文章列可進入；整行保留拖曳及 Shift 選字，hover 的藍金光棒是獨立提示層。
- 已辨識的網址在目前畫面常駐細灰底線，hover 時加亮；沿用 Rust 的連結欄位範圍，包含跨列 OSC 8 的各個片段，不由 UI 再解析文字。ANSI 文字顏色不變，PNG 匯出不包含本機網址底線。換頁或名單遮罩使連結消失時，同一 paint 不再繪製底線。
- 網址與文章編號使用同一個 pointer 交易擁有者，網址優先；拖曳、取消、失焦與失去 capture 不發出導覽。雙擊編號的延續事件不會再開啟一次或選中新頁面。
- 已辨識閱讀畫面在浮球「導覽」分類提供返回／上頁／下頁。依起訖停用無效翻頁；不在文章上蓋透明點擊區。
- 普通滾輪在已辨識的文章／看板／最愛列表與閱讀頁送 Page Up／Down。Ctrl＋滾輪保持縮放；放大後優先捲動可見畫面。選取、dialog、貼上與組字期間不導覽；站端滑鼠回報沿用協商模式。
- 原始 Canvas 維持站端 ANSI 色彩；本機提示、選取與工具列各有獨立層，PNG 不包含導覽提示。

## 輸入交易

同列送一個 CR，其他列使用有限的上下方向鍵加 CR。畫面與輸入的版本在 pointerdown／up、Rust UI 及 connection 擁有者處核對；一次交易至多排入一筆輸入。已送 bytes 無法回滾。等待站端更新期間不重複排入滑鼠導覽；不重試、不跨 session 重送。

Connection 在真正傳送處檢查 generation、Screen revision 與 input epoch，重新從當前 Frame 規劃。手動輸入仍可連續送出；在收到新的終端 bytes 前暫停滑鼠導覽。此更新訊號不等於站端已完成特定動作的協定確認；沒有回覆時保留鍵盤操作。已取消的排隊請求不會延後執行，傳輸錯誤保留實際原因。

測試用自己的合成列表／閱讀畫面，包含雙色字、置底文章、反例、舊 frame、輸入競態及實際 WebView pointer／wheel 往返。人工 PTT 登入、各平台 IME 與跨 DPI 結果另列，不能從合成測試推定。

Windows 桌面 gate 以獨立 loopback 服務端比對完整 bytes，確認編號開啟、上下頁、返回及列表移動；另外驗證按住滑鼠時鍵盤／畫面更新取消點擊、原生 capture 丟失、標題整行選取、編號拖曳、雙擊延續，以及縮放、本機捲動、組字、dialog、未知畫面及頁尾不送額外導覽。hover 前後 Canvas PNG 相同，提示層為透明背景與一像素底線；合成截圖位於 `target/verification/desktop/navigation-list-hover.png` 及 `navigation-reading-controls.png`。


## 整行操作與左緣返回

文章與看板列表的右側四分之三作為開啟區，左側四分之一保留返回；主選單只在選項區第 21–80 欄提供點選，左緣不返回。hover 光棒採 28% 藍色、金色邊框與左右 3px 金色邊緣，呼吸亮度為 80%–100%，不再降至幾乎看不見。維持 2.4 秒呼吸動畫，減少動態效果時使用固定亮度；不修改 Canvas、複製或 PNG。網址命中仍優先；拖動超過既有距離即改為選字，Shift 保留選取。

文章閱讀、文章列表、看板列表、已辨識系統子選單、空列表與命令說明頁的左側四分之一，第 2–23 行提供返回區；hover 顯示垂直提示與向左箭頭游標。標頭／頁尾、主選單、未知、輸入或非 PTT 畫面不提供此入口。返回沿用 Rust Back intent、原來的畫面／輸入版本與 pointer 准入；站端滑鼠模式不被本機返回劫持。點擊須在相同命中與版本按下／放開，拖曳、取消或過期不送出。

舊版僅編號底線的驗證記錄仍代表當時版本；完整列 hover 與左緣返回的 native 驗證以 active plan 當次結果為準。

浮球分類的小選單優先延續扇形展開的左右方向；同側至少有 240×160 像素時使用該側，空間不足才改用其他可容納區域。小視窗仍保留邊界、捲動與返回按鈕，不移動浮球來騰出空間。


系統子選單以獨立 SystemMenu context 處理，先核對已知站端標題／底列配對、說明提示、固定選項欄、完整連續項目及游標記號，再使用原 planner 的相對上下鍵＋CR。主選單與子選單的選項文字不必帶裝飾括號；輸入提示、未知畫面或任意空白區不回退成 Enter。已涵蓋郵件、個人設定、聊天、系統資訊、特別名單等選單外框，沒有宣稱支援其中所有表單或編輯器。看板／最愛的板名與操作欄仍須完整可辨識，描述區不參與輸入決策；該區的無法解碼字不會停用整張列表。分類畫面保留原本較嚴格的完整項目檢查。

2026-10-20 另核對 [公開選單列印介面](https://github.com/ptt/pttbbs/blob/master/mbbsd/menu.c) 與 [看板列表欄位](https://github.com/ptt/pttbbs/blob/master/mbbsd/board.c) 的可見格式，實作與自製案例仍由本專案撰寫；不把公開來源版本當作實站登入驗收。

浮球沿用 App icon 的同一份 Icon Composer 材質渲染圖，透過圓形外殼顯示，向外延伸的 2px 主題金色徽章環保留星尖空間，上緣高光與下緣深金形成玻璃／金屬反光邊緣，星座與返回箭頭共用；三聯星、三條連線及下方突出的小星保持同源。星座為內嵌本機資產，設定品牌仍使用清晰的扁平向量稿。返回圖案、拖曳命中、慣性、透明度及減少動態效果使用既有 owner。


信件列表與精華列表共用 DocumentList 的有界列導航，分別要求「郵件選單」／「精華文章」標題、相符的單份欄位標頭、讀信／讀取資料與返回提示、連續編號及有效游標。UI 只消費 Rust 結果，點擊右側四分之三開啟、左側返回、滾輪 Page Up／Down；未知／多欄標頭、缺列或確認提示不能送出通用 Enter。一般信箱瀏覽不代表新郵件狀態，本項沒有郵件快速跳轉。公開可見欄位格式核對於 2026-10-20，來源為 [mail.c](https://github.com/ptt/pttbbs/blob/master/mbbsd/mail.c) 與 [announce.c](https://github.com/ptt/pttbbs/blob/master/mbbsd/announce.c)；離線自製案例不代表所有實站版型已驗收。

浮球在支援 hover 且未啟用減少動態效果時，以 1.2 秒、最大 1.08 倍的輕微縮放循環提示可點擊；離開或按住即停止，保持原本座標、慣性及扇形配置。

第一層新增直接開啟設定的入口，與原設定／快捷鍵共用對話框，不建立空的工具分類。七個入口按完整半圓重新計算間距。共同 scale 為 clamp(min(viewportWidth/1280, viewportHeight/800), 1, 1.75)，作用於浮球、圖示、扇形半徑、點擊區、字級及工具頁可用空間；resize 保持停靠側與目前分類。使用邏輯 CSS 尺寸，不重複乘 DPR；4K 幾何單元不是實體 4K 螢幕驗收。
