# 滑鼠導覽契約

滑鼠操作沿用固定 80×24 格線。畫面辨識與導覽計畫由 Rust 唯一管理；UI 只消費已辨識的內容與命中區域，不解析文章文字，也不增加 shell／PTY。

目前完成：純 Rust 畫面辨識與輸入計畫、29 個合成正反例、production Connection 的版本／輸入競態往返，以及 Windows Dioxus／WebView2 的真實 pointer／wheel 往返。macOS 另驗證本機列表的 Vim／原生視窗流程；實站登入後及其他平台的滑鼠流程尚未驗證。

## 範圍與識別

第一版保守支援有日期欄的文章列表，以及 pmore 的一般「瀏覽／目前顯示行數」狀態列。需要標頭、操作列、有效項目、游標／選取記號等獨立條件；閱讀需要狀態列的格式、樣式與游標位置。未知畫面、判斷所需欄位的未映射字元、未結束控制碼、缺欄位及非 80×24 都不提供導覽。辨識是 heuristic，終端串流沒有語意畫面協定，不能保證抵抗刻意仿造整頁內容。

閱讀頁尾接受原有「←離開」，或行範圍後完整的 `(y)回應(X)推文(h)說明` 操作列。後者各鍵標籤及說明均須保留狀態列背景，不能因沒有返回提示就暫停翻頁。百分比、有效頁碼及最多 23 行的連續範圍仍逐項檢查；缺鍵、錯鍵、額外提示、正文游標與不完整控制碼不准入。共同辨識結果供一般／Vim 鍵盤、滑鼠、文章快取與傳輸使用。

公開站端介面核對於 2026-10-16，來源為 ptt/pttbbs commit `90f07d655b8d7e85298ef26bdb63f40646fd9d17` 的 [列表欄位與操作](https://github.com/ptt/pttbbs/blob/90f07d655b8d7e85298ef26bdb63f40646fd9d17/mbbsd/bbs.c)、[閱讀狀態列](https://github.com/ptt/pttbbs/blob/90f07d655b8d7e85298ef26bdb63f40646fd9d17/mbbsd/pmore.c)。只依可觀察的文字／欄位介面編寫自己的判斷與合成資料，沒有搬入站端程式或私人 session。這不是實站部署版本的證明。

初期不支援價格式列表、所有自訂狀態列、橫向閱讀或所有彈窗。未辨識時保留手動鍵盤；不猜測自動登入、確認、發文、刪文或轉帳。

文章列依固定格線解析：游標區 1 欄、編號 6 欄、狀態／人氣 4 欄、日期 6 欄、作者 13 欄，後方才是文章標記與標題。人氣與日期可以直接緊貼（如 `+1610/16` 或 `m5110/16`），不能以空白分詞找日期。一般單格 `>` 指標可緊貼六位數編號，不要求後方空白；legacy 圓形指標覆蓋六位數編號首字時，只在該指標列接受數字尾段；不拿可見編號當全域索引。欄位日期／作者／標記仍各自驗證。

看板／最愛以標題色帶、編號／總數、看板、類別、人氣、板主等穩定欄位，以及固定板名欄、操作列與有效指標共同辨識。描述欄名稱（例如「中文敘述」或「中文測述」）不參與輸入判斷；缺少穩定欄位或項目欄位不符時仍暫停，並分別顯示看板標頭／項目欄位未確認。

看板／最愛的前進提示可為「進入」或「閱讀」，返回可為「回上層」、「回到上層」或「離開」；依標頭欄位判定 BoardList，不能僅因提示「閱讀」而判成文章列表。自製滿頁案例包含目錄、長板名、15 列一般文章與 5 列置底，不包含使用者截圖的帳號／最愛內容或私人流量。

一般列表接受五欄日期的補齊空白（例如 `1/ 9`）、一般／回覆／轉錄／投票／鎖文標記，以及作者為 `-` 且帶 `╳`／`□` 的刪文列。一列日期或標記不同不應讓合法看板整頁失去 Vim／滑鼠導覽；一般日期仍須有效；置底星號列另接受日期欄的「重要」。文章可有空白標題，仍須保留已知文章標記、合法編號／作者與完整列表條件；提示列、非法作者或未知標記仍拒絕。格式依 [公開列印介面](https://github.com/ptt/pttbbs/blob/908bb0631a4a6db41eac85713637adf1a6058fde/mbbsd/bbs.c#L711) 編寫自製正反例，沒有將實站登入視為已驗收。

共享辨識器提供主選單、看板／最愛／分類及標準進板暫停提示的鍵盤 profile，詳見 [Vim 瀏覽](vim-browsing.md)。滑鼠也可點選已辨識主選單項目（如個人設定、我的最愛）與看板／最愛／分類列。Rust 提供有效起訖與目前游標列，同一生產 planner 以相對方向鍵加 CR 進入；空白區、標頭與未知畫面沒有命中。此擴充不啟用主選單／最愛的防閒置。文章列表跨上方操作列及底列核對返回／閱讀提示；提示覆蓋不得藉由殘留標頭取得導覽。

## 互動與視覺

- 點已辨識的主選單項目或看板／文章列可進入；整行保留拖曳及 Shift 選字，hover 的藍金光棒是獨立提示層。
- 已辨識的網址在目前畫面常駐細灰底線，hover 時加亮；沿用 Rust 的連結欄位範圍，包含跨列 OSC 8 的各個片段，不由 UI 再解析文字。ANSI 文字顏色不變，PNG 匯出不包含本機網址底線。換頁或名單遮罩使連結消失時，同一 paint 不再繪製底線。
- 網址與文章編號使用同一個 pointer 交易擁有者，網址優先；拖曳、取消、失焦與失去 capture 不發出導覽。雙擊編號的延續事件不會再開啟一次或選中新頁面。
- 已辨識閱讀畫面可在目前可見正文的上半部點擊上頁、下半部點擊下頁，左側 17 欄優先返回；浮球「導覽」亦保留三個操作。沿用正文 pointer 交易，不加會攔截選字或圖片的覆蓋層。
- 普通滾輪在已辨識的文章／看板／最愛列表與閱讀頁送 Page Up／Down。Ctrl＋滾輪保持縮放；放大後優先捲動可見畫面。選取、dialog、貼上與組字期間不導覽；站端滑鼠回報沿用協商模式。
- 原始 Canvas 維持站端 ANSI 色彩；本機提示、選取與工具列各有獨立層，PNG 不包含導覽提示。

正文的返回／翻頁箭頭、選字、推文篩選、進入選單與文章列不顯示基本操作的浮動文字提示；保留箭頭游標、光棒與選取反白。網址 hover 只顯示完整目的地，浮球保留無障礙名稱但不跳出拖曳說明；錯誤、等待狀態及容量限制仍可見。

## 輸入交易

同列送一個 CR，其他列使用有限的上下方向鍵加 CR。畫面與輸入的版本在 pointerdown／up、Rust UI 及 connection 擁有者處核對；一次交易至多排入一筆輸入。已送 bytes 無法回滾。等待站端更新期間不重複排入滑鼠導覽；不重試、不跨 session 重送。

Connection 在真正傳送處檢查 generation、Screen revision 與 input epoch，重新從當前 Frame 規劃。手動輸入仍可連續送出；在收到新的終端 bytes 前暫停滑鼠導覽。此更新訊號不等於站端已完成特定動作的協定確認；沒有回覆時保留鍵盤操作。已取消的排隊請求不會延後執行，傳輸錯誤保留實際原因。

測試用自己的合成列表／閱讀畫面，包含雙色字、置底文章、反例、舊 frame、輸入競態及實際 WebView pointer／wheel 往返。人工 PTT 登入、各平台 IME 與跨 DPI 結果另列，不能從合成測試推定。

Windows 桌面 gate 以獨立 loopback 服務端比對完整 bytes，確認編號開啟、上下頁、返回及列表移動；另外驗證按住滑鼠時鍵盤／畫面更新取消點擊、原生 capture 丟失、標題整行選取、編號拖曳、雙擊延續，以及縮放、本機捲動、組字、dialog、未知畫面及頁尾不送額外導覽。hover 前後 Canvas PNG 相同，提示層為透明背景與一像素底線；合成截圖位於 `target/verification/desktop/navigation-list-hover.png` 及 `navigation-reading-controls.png`。


## 推文暫時篩選的優先序

已辨識標準推文現在可左鍵切換只看該 ID，非網址推文整行優先於下述返回／翻頁；再次點同 ID 或右鍵恢復全部。網址、Shift 與拖曳選字仍優先，其他正文維持下述行為。詳見 [本機過濾](content-filters.md)。

## 整行操作與左緣返回

文章列表的返回區止於日期欄右界（零基第 17 欄前），作者欄起開啟文章；看板列表止於板名前（第 10 欄前）返回，其餘項目區開啟；主選單只在選項區第 21–80 欄提供點選，左緣不返回。hover 光棒採 28% 藍色、金色邊框與左右 3px 金色邊緣，呼吸亮度為 80%–100%，不再降至幾乎看不見。維持 2.4 秒呼吸動畫，減少動態效果時使用固定亮度；不修改 Canvas、複製或 PNG。網址命中仍優先；拖動超過既有距離即改為選字，Shift 保留選取。

返回命中與光棒使用獨立幾何；文章閱讀左側 17 欄、單欄子選單／信件／精華左側 20 欄保留返回，已知列表由第一個內容行開始，標頭／頁尾不攔截。返回 hover 只顯示向左箭頭游標，不繪製框線、底色或左緣提示條；項目 hover 的光棒涵蓋完整列。文章可見正文上／下半部的翻頁區分別顯示向上／向下箭頭游標，與返回箭頭使用相同深色外緣及金色線條，不在文章文字上加框。可見正文最頂／最底各一行（依字高限於 16～32 CSS px，最多佔正文四分之一）改為 Home／End，使用帶橫線的上下箭頭；中間維持上下翻頁。網址與可見推文作者 ID 優先，左緣返回優先於首尾區；標頭／頁尾不納入。網址與選字仍優先使用各自的游標。標頭／頁尾、主選單、未知、輸入或非 PTT 畫面不提供返回入口。返回沿用 Rust Back intent、原來的畫面／輸入版本與 pointer 准入；站端滑鼠模式不被本機返回劫持。點擊須在相同命中與版本按下／放開，拖曳、取消或過期不送出。

快取閱讀的返回區延伸至保留正文各行，提示仍只畫可見左緣一欄，不延伸至頁尾。網址先於返回及翻頁命中；展開圖片的空隙不是 terminal cell，不觸發正文翻頁。翻頁中線依可視正文計算，並隨捲動、視窗大小及縮放更新，不以整篇快取文件的中點劃分。上／下半點擊使用與 Page Up／Down 相同的本機閱讀意圖：先捲動可見高度的 90%，未載入邊界才向站端取頁，已知首尾不送鍵。

展開圖片的實際方框內也沿用左緣返回、可視上／下半翻頁及首尾 Home／End，右鍵仍以圖片連結索引顯示選單。圖片間隙不虛構 terminal cell；從圖片開始拖曳只取消點擊，不產生文字選取。圖片載入、排版、捲動或命中圖片改變會撤銷持有的點擊。

網頁閱讀的非滾輪移動以同一 row layout 對齊行界。PageUp／PageDown 的目標向原可視區取整，保留重疊，避免略過原頁尾未完整呈現的一行；方向鍵／j／k 先依當前行界移動，Home／End 保留實際首尾，不額外增加空白高度。分數縮放、圖片間隙及末頁無法同時對齊上下界時，只呈現完整的文字列，部分文字列與該列展圖控制項暫不顯示；資料、選取與來源 PNG 不刪行。被遮住的邊緣區仍提供返回／首尾／翻頁，不啟動隱藏的文字連結或 ID。滾輪切換為連續顯示，保留原始 pixel offset；下一個離散導覽恢復完整行顯示。

拖曳超過 3px 或按 Shift 保留選字；跨過返回／翻頁分界、失去 capture、組字、modal、站端滑鼠路由或未完成畫面都不啟動正文點擊。閱讀 pointerdown／up／click 除來源 stamp 外另核對文章、投影與可視幾何，按住期間改變捲動、解析度或圖片排版會撤銷該點擊，避免舊位置在新佈局翻頁。未知畫面仍無通用 Enter。

舊版僅編號底線的驗證記錄仍代表當時版本；完整列 hover 與左緣返回的 native 驗證以 active plan 當次結果為準。

浮球分類的小選單優先延續扇形展開的左右方向；同側至少有 240×160 像素時使用該側，空間不足才改用其他可容納區域。小視窗仍保留邊界、捲動與返回按鈕，不移動浮球來騰出空間。


系統子選單以獨立 SystemMenu context 處理，先核對已知站端標題／底列配對、說明提示、固定選項欄、完整連續項目及游標記號，再使用原 planner 的相對上下鍵＋CR。主選單與子選單的選項文字不必帶裝飾括號；輸入提示、未知畫面或任意空白區不回退成 Enter。已涵蓋郵件、個人設定、聊天、系統資訊、特別名單等選單外框，沒有宣稱支援其中所有表單或編輯器。看板／最愛的板名與操作欄仍須完整可辨識，描述區不參與輸入決策；該區的無法解碼字不會停用整張列表。分類畫面保留原本較嚴格的完整項目檢查。

2026-10-20 另核對 [公開選單列印介面](https://github.com/ptt/pttbbs/blob/master/mbbsd/menu.c) 與 [看板列表欄位](https://github.com/ptt/pttbbs/blob/master/mbbsd/board.c) 的可見格式，實作與自製案例仍由本專案撰寫；不把公開來源版本當作實站登入驗收。

浮球沿用 App icon 的同一份 Icon Composer 材質渲染圖，透過圓形外殼顯示，向外延伸的 2px 主題金色徽章環保留星尖空間，上緣高光與下緣深金形成玻璃／金屬反光邊緣，星座與返回箭頭共用；三聯星、三條連線及下方突出的小星保持同源。星座為內嵌本機資產，設定品牌仍使用清晰的扁平向量稿。返回圖案、拖曳命中、慣性、透明度及減少動態效果使用既有 owner。


信件列表與精華列表共用 DocumentList 的有界列導航，分別要求「郵件選單」／「精華文章」標題、相符的單份欄位標頭、讀信／讀取資料與返回提示、連續編號及有效游標。UI 只消費 Rust 結果，點擊項目區開啟、左側 20 欄返回、滾輪 Page Up／Down；未知／多欄標頭、缺列或確認提示不能送出通用 Enter。一般信箱瀏覽不代表新郵件狀態，本項沒有郵件快速跳轉。公開可見欄位格式核對於 2026-10-20，來源為 [mail.c](https://github.com/ptt/pttbbs/blob/master/mbbsd/mail.c) 與 [announce.c](https://github.com/ptt/pttbbs/blob/master/mbbsd/announce.c)；離線自製案例不代表所有實站版型已驗收。

浮球在支援 hover 且未啟用減少動態效果時，以 1.2 秒、最大 1.08 倍的輕微縮放循環提示可點擊；離開或按住即停止，保持原本座標、慣性及扇形配置。

浮球選單或工具分類開啟時，Esc 只關閉本機工具並恢復 BBS 鍵盤輸入焦點，不把這次 Esc 送到站端；下一個方向鍵或 Control 快捷鍵可立即操作，不需再點空白處。若另有開啟的設定／表單對話框，Esc 仍交由該對話框處理，不能提早把焦點搶回 BBS。

新版看板指令列允許以「看板列表／我的最愛／分類看板」底列作為樣式錨點；精簡表頭仍必須保留編號或總數、看板、類別與對應指令。舊「選擇看板」表頭維持人氣／板主的檢查。分類游標依具體版型接受最左欄或第 11 欄，數字欄排除兩格游標；裝飾不影響輸入，項目欄與未知／未映射負例不放寬。

第一層新增直接開啟設定的入口，與原設定／快捷鍵共用對話框，不建立空的工具分類。七個入口按完整半圓重新計算間距。共同 scale 為 clamp(min(viewportWidth/1280, viewportHeight/800), 1, 1.75)，作用於浮球、圖示、扇形半徑、點擊區、字級及工具頁可用空間；resize 保持停靠側與目前分類。使用邏輯 CSS 尺寸，不重複乘 DPR；4K 幾何單元不是實體 4K 螢幕驗收。

根目錄的動態操作列另有兩個具體格式：我的最愛可省略返回提示，但必須同時具備完整的列出全部／進入／找板／搜尋／新文章／排序／上下頁操作列，以及同樣式「我的最愛」頁尾的增加／刪除／新增目錄／移動位置／已讀／說明；分類根目錄可省略進入提示，但頁尾須包含同樣式「分類看板」及加入最愛、已讀、標記、只列最愛與返回。實站鍵標籤為 `(v)已讀/未讀`、`(y)只列最愛`，不沿用錯置的合成標籤。兩種格式仍核對原標頭、固定項目欄、連續項目與有效游標；未知頁尾、提示覆蓋、缺操作或未映射欄位不開放。一般列表沿用原來的雙向提示條件，共同 Rust profile 同時供滑鼠及 Vim 使用。

已確認的 ContinuePrompt 暫停畫面允許整個可見格線單次左鍵點擊繼續，包含網址所在位置與原本左緣返回區。沿用 pointer 按下／放開／click 的來源、投影及可視幾何驗證，送出獨立 Continue 意圖，由 Rust planner 產生一個空白；不能用通用 Open 或 Enter 代替。拖曳、Shift、雙擊第二次、輸出未完成、modal、非本機滑鼠路由與過期畫面仍拒絕。未知畫面不開放此入口；按鍵規則見 [Vim 瀏覽](vim-browsing.md)。


主選單與系統子選單的 hover 光棒和列表一致，從格線最左延伸至最右，不再從選項縮排處開始。命中仍依已辨識的項目列與既有返回區分派。依使用者決定，後續滑鼠增量限於已證實的 PTTStar 操作；未建立完整證據的同列多欄、一般 Y/N 與輸入表單不使用通用 Enter fallback。

## 列表與選單的首尾點擊

已辨識主選單、系統子選單、看板／最愛／分類、文章列表、信件／精華列表與指令說明頁，使用目前可見內容區最頂／最底的一行範圍（16～32 CSS px，最多四分之一高度）提供 Home／End。BBS 格線置中而留下上下黑邊時，另接受整個可視區最頂／最底的同寬窄帶，原格線內的首尾區也保留；黑邊中段仍不觸發操作，不把留白虛構為文字列。格線最底下整條狀態列也可點擊 End，包含左側標籤；閱讀文章的資訊列不適用此列表入口。放大或捲動時仍依實際可視區判定。共用閱讀畫面的首尾幾何與帶橫線箭頭，黑邊游標由 workspace 呈現，不新增覆蓋層；中間仍按原有已辨識列開啟。

連結優先，其次既有左緣返回，最後才是首尾；主選單原本沒有返回區。未知與空列表不提供首尾 fallback。沿同一 Rust First／Last 意圖送出 Home／End，等待站端新畫面時不重複送鍵；來源 stamp、投影、profile、縮放、捲動及幾何變更都撤銷舊點擊。Shift、拖曳、組字、modal、輸出等待及站端滑鼠路由保留原本拒絕規則。原生座標滑鼠仍須人工驗收，JS 與 Connection loopback 不能代替。

每筆 UI 導覽使用遞增的安全整數 request 與 generation；送出、拒絕與取消回覆只結束同一筆等待。一般網頁閱讀方向鍵在未載入邊界走普通取頁來源，跨文章方向鍵才使用專用 keyboard 准入。換篇、換 session、原始輸入、工具與快速跳轉會撤銷舊等待；撤銷只取消尚未執行的工作，不回滾已送 bytes，也不自動重送。內部預讀沒有 UI request，不得用其完成回覆解除使用者的新等待。

置底（★）列另接受作者欄內完整方括號包住、非空且只含 Unicode 字母／數字或底線的顯示名稱；仍須完整 13 欄、可映射、合法日期與文章標記，以及整頁標頭／指令／游標條件。普通編號列仍使用既有帳號規則，僅另接受固定顯示標籤「[彩券]」，保留完整欄寬、日期與文章標記；其他括號標籤、裸名稱、空白、破括號或提示符號不放行。此顯示名稱只供列表結構辨識，黑白名單／作者右鍵仍只接受真正帳號，不能將括號內文字推定為 ID。

主選單的快速前往先在已辨識的連續選項列中找到唯一 `(F)avorite`／最愛項目，使用共同 Open planner 依目前游標送有限相對方向鍵＋CR；已選到該項目時只送 CR。不依賴字母快捷鍵是否直接執行，也不修改站端偏好。缺項、重複項、未知／未完成畫面不送；中途只出現主選單選取更新時繼續等待，不另補 Enter。只有確認看板列表後才送 s，確認空搜尋提示後才送板名，原本版本／取消／期限與唯一送出者契約維持。指定文章入口同樣消費這條切板流程。
