PTTStella 0.2.0 正式版。

- 提供網頁／終端機文章模式、按需展圖、黑白名單、推文標示與 PNG 擷取。
- 改善長文章載入、捲動與記憶體使用，修正切板、換篇、輸入及關閉清理問題。
- 新增 GitHub 正式版本檢查；查詢失敗不影響使用。

下載：Windows x64 安裝版或免安裝版、macOS Apple Silicon／Intel ZIP、Linux x64 DEB／tar.gz。安裝需求與操作請見 [使用說明](https://github.com/yam276/PTTStella/blob/v0.2.0/README.md)。Windows 尚無 Authenticode，macOS 尚未經 Apple 公證。

English: PTTStella 0.2.0 adds smoother article browsing, image previews, local account filters and update checks, with performance and reliability fixes. Downloads are available for Windows, macOS and Linux; see the README for requirements.
