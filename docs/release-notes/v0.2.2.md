PTTStella 0.2.2 修正多開時的資料保存與診斷記錄衝突。

- 設定、黑白名單、書籤與站點會合併不同修改；同一項目衝突時提示，避免互相覆蓋。
- 清空最近看板後，其他視窗不會把舊紀錄寫回；書籤合併超出容量時安全拒絕。
- 修正設定自動儲存尚未回報時立即關窗，最後一次修改可能無法保存的問題。
- 診斷版每次啟動使用獨立記錄，保留有界容量並保護仍在寫入的紀錄。
- 包含分開 ANSI 控制碼的半格色彩相容修正。

使用前請關閉舊版，避免舊版與新版同時修改資料。多開仍受 PTT 站端連線限制。公開下載包含 Windows、macOS、Linux 套件與 SHA256SUMS；建置資訊 JSON 留在 Actions artifacts。

English: Fixes concurrent-instance settings/list persistence, recent-history clearing and isolated diagnostic logs. Includes an ANSI half-cell colour compatibility fix. Close older versions before using this update; PTT connection limits still apply.
