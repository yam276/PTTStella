PTTStella 0.3.0 加入文章收藏、推文更新與編輯上色，並改善日常操作。

- 從文章或列表標題一鍵收藏，保存文字、ANSI 色彩與推文，可離線閱讀；無標頭的 ANSI 圖文章也支援。
- 文章可每五秒檢查推文；更新保留閱讀位置，可暫停，離開文章即停止追蹤。
- 編輯器提供 PTT 色彩表與框選上色，多行逐行處理，保留 Ctrl+V 彩色預覽。
- 支援文字名單匯入及分類顏色，新增醒目的操作通知與斷線重新連線按鈕。
- 精簡浮球選單，將收藏放在第一層；修正 ANSI 放大黑線、上色逾時與文章導覽誤報。

macOS 尚未經 Apple 公證；首次開啟方式見 README 的「隱私權與安全性 → 強制打開」。圖片僅保存網址，不包含在文章離線副本。

English: Adds one-click article bookmarks with offline ANSI copies, optional five-second reply checks that preserve reading progress, selection colouring, list import colours and reconnect notifications. Fixes ANSI zoom seams, editor colouring timeouts and article navigation errors.
