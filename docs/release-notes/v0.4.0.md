PTTStella 0.4.0 加入本機撰寫與草稿恢復，並改善推文定位、圖片操作與文字顯示。

- 本機編輯器保留中文與 ANSI 色碼，支援彩色編輯、隱藏色碼、色碼原文及右鍵色票；可選部分文字、整行或字格矩形。先取得看板分類與預設範本，自動保存草稿，斷線或重開後可恢復；多開衝突另存副本。確認帶回 PTT 後仍由使用者自行發表。
- 推文以藍金側標辨識自己與原作者，提供快速定位；保留黑白名單與連推合併。浮球「收藏」直接開啟已存文章清單。
- 全螢幕 BBS 四周留白也可滑鼠導覽；完整圖片預覽支援滾輪縮放與拖曳。
- 新安裝預設採 Windows 傳統 BBS、字高 23，新增文字寬度調整與字型重設；修正括號下緣裁切、縮放後英文字高與基線錯位。既有設定會保留，細明體需先合法安裝，也可選用內建跨平台字型。
- 複製、存檔與收藏等成功通知會自動淡出，滑鼠停留或鍵盤聚焦時暫停；需要處理的錯誤持續保留。
- 修正實站草稿帶回因檔尾 `~` 標記或分段重繪而停止的問題；中文、ANSI、空白行與尾端換行已在 Test 板驗證，未發表測試文章。

macOS 尚未經 Apple 公證；首次開啟方式見 README 的「隱私權與安全性 → 強制打開」。
