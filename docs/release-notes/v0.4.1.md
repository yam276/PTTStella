PTTStella 0.4.1 加入 PTT SSH／WSS 切換，以及 Windows／Linux 系統密碼庫保存。

- 在「連線 → 站點」選擇 PTT（SSH）或 PTT（WSS），再按「連線切換」。SSH 使用 PTT 官方 Big5-UAO 入口並驗證站方主機金鑰。
- 一般連線停用 Telnet 與明文 WebSocket。舊明文預設會在啟動時改用 PTT WSS，並提示重新選擇。

- Windows 使用認證管理員。Linux 使用桌面的 Secret Service，例如 GNOME Keyring，需要工作階段 D-Bus 與可用的密碼庫。
- 登入視窗預設不勾選保存。下次可以留空密碼欄並按登入，或移除已存帳密。密碼庫無法使用時，取消勾選並輸入帳密即可單次登入。
- 發佈流程加入 Windows 與 Linux 的原生密碼庫測試，驗證勾選保存、跨程序讀回、帳號不符與移除。Linux 也檢查缺少服務時的處理。

English summary

Switch between PTT WSS and host-key-verified SSH in Stations. Regular connections require encryption. Windows and Linux can save credentials in Credential Manager and Secret Service after you opt in. Click Log in to reuse a saved password.
