PTTStella 0.4.1 為 Windows 與 Linux 加入系統密碼庫保存。

- Windows 使用認證管理員。Linux 使用桌面的 Secret Service，例如 GNOME Keyring，需要工作階段 D-Bus 與可用的密碼庫。
- 登入視窗預設不勾選保存。下次可以留空密碼欄並按登入，或移除已存帳密。密碼庫無法使用時，取消勾選並輸入帳密即可單次登入。
- 發佈流程加入 Windows 與 Linux 的原生密碼庫測試，驗證勾選保存、跨程序讀回、帳號不符與移除。Linux 也檢查缺少服務時的處理。

English summary

Windows and Linux can save credentials in Credential Manager and Secret Service after you opt in. Click Log in to reuse a saved password. Release builds exercise native persistence and deletion on both platforms.
