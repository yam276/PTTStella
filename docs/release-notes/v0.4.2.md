PTTStella 0.4.2 修正 Linux（GTK／Wayland）關窗後程序殘留背景的問題，並加入選用自動開圖、超長文章分段接續、大型 GIF 支援與 macOS DMG 安裝映像。

- 修正 Linux（GTK／Wayland）點擊視窗關閉按鈕後，因隱藏視窗暫停 `requestAnimationFrame` 而使 Dioxus DOM 更新佇列阻塞，導致 `pttstella` 與 WebKit 子程序持續殘留背景的問題（[#10](https://github.com/yam276/PTTStella/issues/10)）。
- 「設定 → 圖片與媒體」新增「進入文章時自動開圖」，預設維持手動開圖。
- 網頁閱讀模式支援超過單段快取上限的長文分段接續載入，並放寬文章預覽與文內展開的 GIF 動畫容量限制。
- macOS 除既有 `.zip` 外，新增提供 `.dmg` 拖曳安裝磁碟映像檔。

English summary

Fixes a Linux (GTK/Wayland) shutdown hang where hiding the window on close suspended `requestAnimationFrame` and left `pttstella` and WebKit subprocesses running in the background (#10). Adds optional automatic article image expansion, segmented continuation for very long articles in web reading mode, higher GIF animation memory limits, and drag-to-install macOS `.dmg` disk images alongside `.zip` archives.
