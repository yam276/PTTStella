PTTStella 0.5.0 改用 Slint 原生介面，不再依賴 WebView；影片改由 libmpv 播放，授權改為 GPL-3.0-or-later。

- 介面改以 Slint 原生繪製。Windows 不再需要 WebView2，Linux 不再需要 WebKitGTK。在 Apple Silicon 上單一視窗最小化閒置的量測中，記憶體約 99 MiB，0.4.x 約 680 MiB。
- 影片改用 libmpv 播放。macOS 與 Windows 內附播放元件；Linux 使用系統的 `libmpv2`，沒有安裝時只停用影片並提示安裝，其他功能照常。
- 可直接覆蓋 0.4.x 安裝，沿用原本的設定、收藏、草稿與系統密碼庫中保存的帳密。macOS 第一次讀取已保存的密碼時，系統可能詢問是否允許存取鑰匙圈。
- Windows 免安裝版改為 `-portable.zip`：解壓縮後執行 `pttstella.exe`，並讓它與旁邊的 DLL 放在同一個資料夾。
- 每個平台另附 `-sources.tar`，提供本版套件與內附播放元件的原始碼或取得資訊。
- 移除文章左上角「推文定位」與左下角「返回網頁閱讀」浮動按鈕。推文定位改從文章右鍵選單或浮球工具開啟。
- 網頁閱讀模式加入與終端分頁相同的滑鼠首頁／末頁區。按住滑鼠時游標維持導覽箭頭，開始拖曳選取才換成文字游標。
- 修正文章已到 100% 時，底部狀態列有時顯示過渡中的顏色而不是藍色。
- 授權改為 GNU GPL 第 3 版或（由你選擇）任何更新版本，讓 macOS 版可內附 GPL 版的 mpv／FFmpeg。

English summary

PTTStella 0.5.0 moves to a native Slint interface and no longer needs a WebView: Windows drops the WebView2 requirement and Linux drops WebKitGTK. Videos now play through libmpv, bundled on macOS and Windows; on Linux the system `libmpv2` is optional and only video is disabled without it. Installing over 0.4.x keeps settings, bookmarks, drafts and saved credentials. The Windows portable download is now a ZIP, and each platform ships a `-sources.tar`. The floating reply-locate and resume-reading buttons are removed, web reading gains the terminal's mouse Home/End bands, and the 100% footer colour is fixed. PTTStella is now licensed under GPL-3.0-or-later.
