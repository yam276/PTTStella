PTTStella 0.5.1 修正 0.5.0 網頁閱讀與滑鼠操作的幾個問題：進出文章不再縮放畫面，首尾頁與圖片旁的點擊更符合直覺。另修正 PTT（SSH）可能無法連線的問題。

- 進出文章時，PTT 畫面不再快速縮放或位移，底部也不再多出一條空白列。網頁閱讀現在與終端畫面使用同一個 BBS 框與列高；右側捲軸疊在邊緣，只有放大到超出視窗寬度時才在底部顯示水平捲軸。
- 終端分頁與網頁閱讀的滑鼠首尾頁改為最上一列為 Home、底部狀態列整列為 End。0.5.0 的 End 誤落在倒數第二列。網頁閱讀在 BBS 框外的上下黑邊也與終端畫面相同，可點擊翻頁或回到首尾。
- 文章中展開圖片後，圖片兩側的空白也能點擊：左側返回，其他位置依上下半翻頁。點圖片本身仍開啟預覽。
- 移除滑鼠移到網址上時，畫面底部出現的網址列。這條列會蓋住底部狀態列，換頁後也可能突然閃出。網址仍以手形游標提示，點擊與複製完整網址不變。
- 按住滑鼠時維持導覽箭頭，不再顯示系統預設游標；開始或結束拖曳選字時，文字游標立即切換。
- 切換到 PTT（SSH）時，站端若在回覆終端請求前先調整傳輸視窗（OpenSSH 的做法），PTTStella 不再誤判為拒絕並顯示「無法連線: SSH terminal request refused」。

English summary

PTTStella 0.5.1 fixes web reading and mouse issues from 0.5.0. Entering or leaving an article no longer rescales or shifts the PTT screen, and the empty strip at the bottom is gone: web reading now shares the terminal's BBS box and row height. The mouse Home and End zones are now the top row and the footer status bar in both terminal and web reading, and the black bands outside the box page like the terminal's. The blank space beside an expanded image now goes Back or pages instead of ignoring clicks. The bottom link URL bar, which covered the status row and could flash after a page change, is removed. The navigation cursor no longer turns into the system arrow while the mouse is held, and the text cursor switches as soon as a selection drag starts or ends. PTT (SSH) no longer fails with "SSH terminal request refused" when the server adjusts the transfer window before answering the terminal request, as OpenSSH does.
