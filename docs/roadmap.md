# 開發順序

當前唯一交付為 [最簡 PTT terminal](active/minimal-browser.md)：先讓文字／排版可靠，再接一條加密連線，由使用者手動登入。階段狀態只維護於 active plan。

後續已加入保守畫面辨識／滑鼠導覽，並依 [媒體規格](media.md) 實作按需預覽。仍不做獨立文章模型、板名導覽按鈕、現代文章介面、追蹤、書籤或啟動時自動登入。macOS 的明確按鈕登入與鑰匙圈保存依 [登入契約](login.md)。先不把跨平台發佈、完整 IME／剪貼簿與進階 UI 當成首次登入原型的前置工作；必要輸入與可用顯示仍須實測。

第一個原型在 Windows 驗證；macOS／Linux 後續使用同一核心與顯示案例，各自建立真實 backend 結果。不以 Windows 成功宣稱三平台完成。

後續操作能力先依使用者需求研究，候選方案與驗收見 [操作功能研究](feature-research.md)：選取／複製、IME／貼上、網址、ANSI Art 截圖及字型設定。研究不改變首次登入原型的完成條件；功能實作以後續選定的範圍逐項交付。
