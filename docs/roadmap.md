# 開發順序

當前唯一交付為 [最簡 PTT terminal](active/minimal-browser.md)：先讓文字／排版可靠，再接一條加密連線，由使用者手動登入。階段狀態只維護於 active plan。

目前不做文章模型、畫面辨識、板名導覽按鈕、現代文章介面、圖片、追蹤、書籤或自動登入。先不把跨平台發佈、完整 IME／剪貼簿與進階 UI 當成首次登入原型的前置工作；必要輸入與可用顯示仍須實測。

第一個原型在 Windows 驗證；macOS／Linux 後續使用同一核心與顯示案例，各自建立真實 backend 結果。不以 Windows 成功宣稱三平台完成。

只有 terminal 登入流程與顯示契約完成後，再依使用者需求規劃瀏覽與其他功能，避免把後續能力提前變成當前 MVP 範圍。
